기능 설명 功能说明 · Function Guide

구분 分类한국어中文설명 说明
① 승하강상승 / 정지 / 하강上升 / 停止 / 下降전동 리프트로 빨래대를 올리고 내림. 이동 중 상·하 버튼을 다시 누르면 즉시 정지. 电动升降，运行中再次按上/下键即停止。
① 승하강 추천 推荐높이 메모리 (M1·M2)高度记忆자주 쓰는 높이를 저장해 한 번에 이동. 保存常用高度，一键到位。
② 조명전원 / 색온도 / 밝기电源 / 色温 / 亮度LED 조명 켜기·끄기, 전구색↔주광색 조색, 밝기 조광. LED开关、色温调节、亮度调光。
② 조명조명 메모리照明记忆마지막 색온도·밝기 설정을 기억해 다음에 그대로 켜짐. 记忆上次色温与亮度设置。
③ 건조·바람열풍 / 자연풍热风 / 自然风열풍(가열 건조)과 자연풍(일반 송풍) 전환. 热风烘干与自然风送风切换。
③ 건조·바람세기 1·2·3 (약·중·강)风力 1·2·3（弱·中·强）열풍·송풍 각각 단계별 세기 조절. 热风与送风均可分档调节强度。
③ 건조·바람타이머 (30분~3시간)定时（30分钟~3小时）설정 시간 후 자동 정지. 到时自动停止。
④ 씬 추천 推荐널기 / 건조 / 정리晾晒 / 烘干 / 收纳원터치로 높이·건조·타이머를 한 번에 실행. 一键联动高度、烘干与定时。
④ 씬 추천 推荐UV 살균UV 紫外线杀菌자외선(UV) 램프로 빨래·건조대를 살균해 세균·냄새 억제. 紫外线UV杀菌，抑制细菌与异味。
