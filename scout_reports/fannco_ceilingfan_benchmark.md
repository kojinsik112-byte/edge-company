## 0. 데이터 출처 한계 (솔직 고지)
- 네이버 스마트스토어는 본 환경의 **모든 접근 도구(Chrome MCP·WebFetch)에서 하드 차단**됨 → 원본 상세페이지 레이아웃/리뷰수/실제 카피는 직접 확인 못 함.
- 대신 **동일 제품군 미러(큐브라이팅 입점 페이지)** + 팬앤코 본사몰 검색 인덱스에서 **실측 스펙·셀링포인트 순서**를 확보. 아래 스펙은 신뢰 가능, "상세페이지 섹션 구성"은 미러 기준 추정.
- 원본 페이지의 정확한 리뷰수·섹션 순서·배너 카피가 필요하면 → **회장님 스크린샷 1~2장**이면 100% 확정 분석 가능.

## 2. 셀링포인트 강조 순서 (경쟁사 패턴)
1. 공기순환 효율 — 정/역방향, 냉난방비 절감
2. **SIDS(영아돌연사) 위험 72% 감소** ← 감성·육아맘 후킹
3. 저소음 35dB "도서관 수준"
4. 반영구 BLDC 모터 (내구·정숙)
5. 안전 — 진동테스트·다중 인증
6. 스마트 — i-Feel, 3색 LED

## 3. 분해된 '잘 팔리는 패턴' (아크로가 훔칠 전략 X / 이길 전략 O)
**경쟁사가 잘하는 것**
- 숫자 후킹: 35dB, 72%, 2년AS, 5단계 — 입증가능 수치로 신뢰 확보(과대광고 회피)
- 감성 트리거: SIDS/육아맘 등 '이유 있는 구매' 서사
- RF리모컨·정역방향 = 기능 차별점을 명확히 분리 서술
- 24개 모델 라인업 = 인테리어 선택권

**경쟁사 빈틈 = 아크로 공략 포인트**
1. **풍량(CMM) 수치 부재** → 아크로는 "풍량 ○○CMM" 인포그래픽으로 정면 비교 우위. (CLAUDE.md상 아크로 승부처와 정확히 일치)
2. **소음을 '도서관' 비유로만** 처리 → 아크로는 dB 거리별 실측 그래프(취침시 ○○dB)로 시각 신뢰 ↑
3. **색온도 3색을 글로만** → 색온도 K값 비주얼 바(2700K~6500K) 인포그래픽
4. **설치높이/천장고 가이드 약함** → 설치 적합 천장고·낙하안전 시각 가이드로 안심 요소
5. 디밍을 '밝기조절'로 뭉뚱그림 → 디밍 % 단계 시각화

## 4. 아크로 상세페이지 권장 섹션 골격 (planner 인계용)
1. 히어로 — 제품 비주얼 + 핵심 1줄(수치 후킹)
2. **스펙 인포그래픽 존**: 풍량 CMM / 소음 dB거리그래프 / 색온도 K바 / 디밍% / 소비전력 — ★승부처
3. 모터 기술(BLDC) 정숙·반영구
4. 정/역방향 사계절 효율(절감 시나리오)
5. 안전·인증(KC) + 설치 천장고 가이드
6. 리모컨/스마트 기능
7. 신뢰(AS기간·리뷰·인증마크)
8. 옵션/사이즈 셀렉터 + FAQ
