## 4. 전략
### 공통
1. **숏츠 우선 양산**(주 3~5개). 숏폼은 구독자 무관 노출 → 도달을 새로 만든다. 작동한 훅(부도·망함·충격발언·비포애프터) 반복.
2. **조회/시청시간** 지표를 KPI로(구독자 수 X). 시청유지율 높은 30~45초 숏츠 설계.
3. 구독자 1.5만은 **PT·상세페이지의 신뢰배지**로만 활용("유튜브 1.5만 채널 운영").

### 주관사 채널(B2B·입주민)
- 내부고발/경고 훅 숏츠("이런 주관사 피하세요", "발전지원금의 진실") → 입주예정자협의회 유입 → 단지 PT 신뢰자산.
- 타깃 = 입주민·협의회. 조명/제품 섞지 말 것(주관사 정체성 유지, 메모리 jugansa-only 원칙).

### 조명·커튼 채널(B2C)
- 이름 유지("우리집에 조명 보러갈래?") + 포지셔닝 확장(조명·커튼·인테리어). 재생목록 분리.
- 포맷: **셀프시공 비포애프터 숏츠**(우물조명 20분·실링팬 설치·커튼 시공) = 검증된 반응.
- 퍼널: 숏츠 → 아크로 스토어(edge2050)·엣지리브커튼 구매 연결.
