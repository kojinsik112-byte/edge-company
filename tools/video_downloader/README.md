# 엣지컴퍼니 유튜브 영상 추출기

유튜브 주소 → 화질 선택(4K·1080p·720p·480p… / MP3) → MP4 파일로 저장.

## 처음 한 번 (윈도우)
1. 파이썬 설치: https://www.python.org/downloads/ (첫 화면 **Add python.exe to PATH** 체크)
2. 이 폴더의 **`설치.bat`** 더블클릭 (1~3분, ffmpeg까지 자동 설치 — 따로 깔 것 없음)

## 매번 쓸 때
1. **`실행.bat`** 더블클릭 → 창이 뜸 (유튜브 주소를 복사해 두면 자동으로 붙여넣어짐)
2. **[화질 조회]** → 목록에서 화질 선택 (화질·예상 용량·코덱 표시)
3. **[⬇ 다운로드]** → 완료 후 **[폴더 열기]**
   - 기본 저장 위치: `내 PC\다운로드\유튜브추출\` (제목 [1080p].mp4)

| 옵션 | 설명 |
|---|---|
| 편집·호환 우선 (기본 ON) | H.264 MP4 우선 → 캡컷·윈도우 기본 플레이어에서 바로 재생. 1440p·4K는 유튜브가 H.264를 안 주므로 VP9로 받음 |
| 음원만 (MP3) | 192kbps MP3 추출 (BGM·나레이션 참고용) |

## 🎬 캡컷 AI 편집기 연결 (다운로드 → 숏츠 자동)
받은 영상을 `캡컷 ai편집기`로 바로 넘겨 **숏츠·자막·썸네일·업로드정보(제목/설명/해시태그)**를 뽑습니다.
결과는 기존과 같이 **바탕화면 `캡컷_완성본\(영상제목)\`**.

- **가장 쉬운 길**: `주소로숏츠만들기.bat` → 주소 붙여넣기 → Enter (1080p 다운 + 재가공 자동)
- **창에서**: ④ 캡컷 AI 편집 연결 → "다운로드 끝나면 바로 보내기" 체크, 또는 완료 후 **[🎬 캡컷 편집 보내기]**
- **명령줄**: `yt_downloader.py 주소 -q 1080 --edit` (풀 편집은 `--full-edit`)

| 모드 | 언제 | 하는 일 |
|---|---|---|
| **재가공 (기본·추천)** | 유튜브에 이미 올린 완성 영상 | 컷 없음. 자막·숏츠(9:16)·썸네일·업로드정보만 |
| 풀 편집 | 촬영 원본(편집 전)을 올렸다 받은 경우 | 무음·추임새·AI 스마트컷·인트로/BGM까지 |

> 완성 영상에 풀 편집을 쓰면 **말 없는 제품컷·BGM 구간이 잘려나갑니다** → 재가공이 기본인 이유.
> 캡컷 편집기는 처음 한 번 `캡컷 ai편집기\설치.bat` 이 필요합니다. 위치가 다르면 환경변수 `EDGE_CAPCUT_DIR` 로 지정.

## 오류가 나면
유튜브는 수시로 구조를 바꿔서 다운로더가 막힙니다 → **`업데이트.bat`** 실행 후 재시도.
비공개·연령제한·회원전용 영상은 받을 수 없습니다.

## 명령줄(자동화용)
```bat
.venv\Scripts\python yt_downloader.py "https://youtu.be/..." --list          :: 화질 목록만
.venv\Scripts\python yt_downloader.py "https://youtu.be/..." -q 1080         :: 1080p 저장
.venv\Scripts\python yt_downloader.py "https://youtu.be/..." -q mp3 -o D:\BGM
```
요청 화질이 없으면 그 아래 최고 화질로 자동 대체.

## 사용 범위 (중요)
- ✅ **우리 채널 2개(인테리어·커튼·조명) 영상 원본 백업·재편집**, 허락받은 협력사·고객 영상, CC 라이선스 영상
- ❌ 타 채널 영상을 받아 재업로드·상세페이지 삽입 = 저작권 침해 + 유튜브 약관 위반
  (경쟁 영상은 **구성·후킹 분석용 참고**까지만 — 회사 절대규칙 1번과 동일)

## 구조
- `yt_core.py` — 엔진 (화질 목록·포맷 선택·다운로드·병합). yt-dlp + imageio-ffmpeg
- `yt_downloader.py` — 창(tkinter) + 명령줄
- `capcut_bridge.py` — 캡컷 AI 편집기 연결 (편집하기.bat 호출, 재가공/풀 편집 모드)
