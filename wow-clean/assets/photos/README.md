# 와우클린 실제 시공 사진 넣는 곳

이 폴더에 아래 파일명으로 사진을 넣으면 사이트에 **자동으로** 실사진이 뜹니다.
(파일이 없으면 깔끔한 플레이스홀더가 대신 보이므로 사이트는 절대 깨지지 않습니다.)

## 로고 · 모델 (우선 권장)

| 파일 위치 | 쓰이는 곳 | 파일 |
|---|---|---|
| `wow-clean/assets/logo.png` | 헤더 로고 (자동 표시) | WOW CLEAN 와우클린 로고 (배경 투명 PNG 권장) |
| `wow-clean/assets/photos/model.jpg` | (선택) 히어로/브랜드 모델컷 | 파란 유니폼 모델 포스터 |

로고 PNG를 넣으면 헤더의 임시 워드마크가 **실제 로고로 자동 교체**됩니다.

## 넣는 방법
1. **GitHub 웹**: 이 저장소 → `wow-clean/assets/photos/` 폴더 → `Add file > Upload files` 로 위 파일명으로 업로드
2. 또는 회장님이 파일로 전달 → 본부장(Claude)이 넣어드림

## 주의 (회사 규칙)
- 사진에 **고객 개인정보(상호 간판·주소·얼굴)**가 크게 보이면 가리거나 크롭 후 사용.
- 용량이 크면(4MB↑) 적당히 줄여서 올리면 로딩이 빨라집니다.
