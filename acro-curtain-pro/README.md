# ACRO CURTAIN PRO — 커튼·블라인드 실측 계산기

현장 실측 담당·견적 담당·시공 담당이 휴대폰과 PC에서 쓰는 커튼·블라인드 원단 산출 및 견적 계산기.
서버 없이 브라우저에서 계산하고, 모든 데이터(고객 정보 포함)는 그 기기의 브라우저에만 저장된다.

## 바로 쓰기
- **PC·휴대폰 브라우저**: `release/ACRO_CURTAIN_PRO.html` 파일을 크롬으로 연다. 인쇄·PDF 저장, JSON 파일 저장/불러오기까지 된다.
- **Claude 미리보기(Artifact)**: `release/acro-curtain-pro.artifact.html`. 미리보기 화면은 인쇄 창과 파일 다운로드가 막혀 있어 견적서는 미리보기·복사, JSON은 복사·붙여넣기로 대신한다.

## 휴대폰용 웹 주소 (Vercel, 엣지컴퍼니 홈페이지와 별개)
- `npm run deploy` = `build:web` → `dist-web/` 를 Vercel 별도 프로젝트로 운영 배포.
- web 빌드는 홈 화면 추가(manifest·아이콘 `pwa/`), 오프라인 서비스 워커(`pwa/sw.js`), 검색 제외(noindex)가 들어간다.
- 데이터는 휴대폰마다 그 브라우저에만 저장된다. 기기 간 이동은 환경설정 → JSON 내보내기/불러오기.

## 개발
```bash
npm install
npm run dev          # http://localhost:5178
npm test             # 계산 공식 단위 테스트 (명세 테스트 A~E 포함)
npm run build:all    # release/ 에 단일 HTML 2종 생성
```
React 18 + TypeScript + Tailwind CSS 3 + Vite. 빌드 결과는 외부 파일이 필요 없는 단일 HTML(폰트만 Google Fonts, 오프라인이면 시스템 글꼴).

## 계산 규칙 (src/lib)
| 파일 | 내용 |
|---|---|
| `curtain.ts` | 주름 적용 가로 = 실측 가로 × 주름 배수. 폭 수는 **현장 기준(기본)**: 필요 가로 ÷ 원단 1폭의 남는 소수가 0.2폭 이하면 버림(3.10폭 → 3폭), 양개는 전체 폭을 반폭 단위로 좌우 배분(1.5 + 1.5). **엄격 올림**으로 바꾸면 소수 발생 시 올림, 양개는 좌·우를 각각 올림. 봉제 손실·옆단 여유를 넣으면 유효 폭(N×폭 − 이음×손실 − 2×옆단)으로 계산. 폭당 재단 길이 = (세로 + 상단 + 하단 + 기타) × (1 + 수축%) → 무늬 반복 또는 재단 단위로 올림(둘 중 하나만). 광폭 원단형은 원단 폭 ≥ 제작 높이를 검사하고 롤 길이 방향 사용량을 계산. |
| `blind.ts` | 주름 배수 없음. 주문 사이즈 = 실측 − 차감 + 추가 → 반올림 단위. 실측 면적·주문 면적·청구 면적(최소 청구 규격·최소 면적·면적 올림)을 따로 계산. 제조사 기준 미입력 시 「제작 기준 확인 필요」. |
| `quote.ts` | m당 단가 = 총 소요 원단(m) × 단가, 폭당 단가 = 폭 수 × 단가. 공간별 할인 → 출장·배송비 → 현장 할인 → 부가세(별도/포함/미적용) → 끝전 절사. 원가·마진은 관리자 화면에만. |
| `num.ts` | 부동소수 잡음 제거 후 올림(`ceilSafe`) — 330.00000000000006 같은 값이 폭 하나를 더 만드는 오류 방지. |

제조사마다 다른 수치(봉제 손실, 옆단, 수축률, 블라인드 공제·최소/최대 규격, 최소 청구 면적 등)는 확정하지 않고 모두 0(미적용)으로 시작한다. 환경설정에서 입력한다.
