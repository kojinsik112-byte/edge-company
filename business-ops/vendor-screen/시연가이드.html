① 사전 세팅 (발표 전날 + 당일 아침)

  • 그 노트북에서 사이트 미리 열고 검색·엑셀 업로드 1회 테스트
  • 휴대폰 핫스팟 ON (행사장 와이파이 백업)
  • 데모 엑셀을 노트북에 저장
    (유림노르웨이숲_업체리스트_샘플.xlsx)
  • 깨끗하게 나오는 시연용 업체명 1~2개 미리 확인
  • 브라우저 즐겨찾기에 사이트 등록 (빠른 접속)
  • 화면 밝기·글자 확대(필요 시 Ctrl + +)

② 언제 시연하나

업체 선별 기준(리조트형) 설명 직후.

"저희는 '검증한다'고 말로만 하지 않습니다.
지금 직접 보여드리겠습니다."
→ 노트북 화면으로 전환

⏱ 시간

전체 60~90초 안에. 길게 끌지 않기 — 짧고 강하게.

③ 시연 흐름 (순서대로)

동작화면에 뜨는 것한 마디 (예시 — 회장님 말로)
1단일 업체 검증
업체명 입력 → "검증 실행"		레이더 스캔 → 신호등 판정 + 카페·블로그 글"지금 네이버 카페를 실시간으로 뒤집니다. 가짜 시연 아닙니다."
2리스트 일괄 탭 클릭
→ 엑셀 업로드		참여업체 명단이 자동으로 좌르륵 입력"유림 노르웨이숲 참여업체 전부를 한 번에 검증합니다."
3"일괄 검증 시작"신호등 표 실시간 채워짐 (위험 업체 맨 위로)"사고 이력이 있는 업체는 입주민 앞에 못 섭니다."

④ 돌발 대비 (Plan B)

  • 인터넷 끊김 → 핫스팟으로 즉시 전환
  • 그래도 안 되면 → 미리 찍어둔 스크린샷으로 설명
  • 동명 업체·이상한 결과 →
    "이래서 마지막은 사람이 교차검증합니다" 로 받기

⑤ 절대 하지 말 것

🔴 실제 경쟁업체명을 무대에서 즉흥 검색 금지
(빨간불 뜨면 공개 석상 명예훼손 위험)

"특정 업체 저격"이 아니라 "시스템이 전 업체를 한 번에 훑는다"를 보여주는 것.
