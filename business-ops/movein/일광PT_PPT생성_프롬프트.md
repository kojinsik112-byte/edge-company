## §1. 마스터 프롬프트 (Gamma·ChatGPT·Copilot 등에 복붙)

```
너는 프레젠테이션 디자이너다. 아파트 입주박람회 '주관사 선정' 공개 PT(40분, 청중=입주예정자협의회+입주민) 슬라이드를 만든다.

[디자인]
- 화이트 배경 + 네이비(#0e1830) / 골드(#c9a961) 포인트. 고급 부동산 IR 톤.
- 슬라이드당 메시지 1개. 큰 숫자는 크게(예: "1억", "83만원", "22,065세대").
- 표지는 단지 드론 항공샷 배경(이미지는 내가 넣음 — 자리만 비워둘 것).
- 과장 표현 금지: "최고/유일/100% 만족/완벽" 금지. 숫자로만 말한다.

[회사 핵심 팩트 — 그대로만 사용, 창작 금지]
- ㈜엣지컴퍼니. 대표 고진식(온산 대한유화 10년 후 창업, 저서 '사람 덕분에 여기까지 왔습니다'). 본부장 하혜정.
- 건설업·전기공사업·소방시설업 면허 보유 = 직접 시공·A/S 법인. ISO 9001/14001/45001, 한국기업평가 BB-, 자본금 2억, 14개 지사, 삼성전자 MOU.
- 실적: 13개+ 단지 22,065세대(전부 1,000세대 이상), 2024·2025 부산 입주물량 70% 이상 주관, 기장 유림노르웨이숲(165세대, 같은 시행사·같은 브랜드) 기주관.
- 사옥: 현장에서 차로 20분, 60평(회의실은 협의회에 무료 대여).
- 핵심 약속: 협약식과 동시에 자사 현금 1억 원을 '입예협+주관사 공동통장'에 예치, 집행권은 협의회 단독. 이행보증보험(하자) 5억. 부산·경남 지역업체 100% 구성 — 못 지키면 주관사 자격 철회 동의서에 현장 서명. 10년 A/S(최소 2년 무상), 48시간 하자보수, 시공일정 100% 보장(지연 시 하루 5만 원), 베이스캠프 1개월.
- 혜택: 박람회 '방문(체크인)만 해도' 전 세대 동일 — 전동커튼 28만+간접조명 20만+거실 미세방충망 20만+상품권 15만 = 약 83만 원 상당 + 화재보험 무료. 계약 조건 없음.
- 시스템: ①클린벤더(업체 평판 실시간 검증 웹, 라이브 시연) ②입주민 전용 앱(실거주 인증·검증 협력사·A/S 게시판, 라이브 시연) ③매일 아침 업체 자동감시(카톡 보고). 네이버 밴드 지역 협력사 약 1,300곳.
- 유리난간: 부산 첫 주관사 주도 공동구매 완주(에코델타 푸르지오린 120세대). 시공파트너 ㈜중원유리산업(유리난간 특허 10-2228988·전용방충망 특허 10-2618014, 삼성화재 배상책임보험, 같은 기장군 쌍용오시리아 2025 시공). 이 단지 전용 단가표 확보: 거실 개인 320만→10세대 이상 공동구매 200만(37.5% 절감), 안방·작은방 각 60만, 전용 방충망 20~50만. 동의 요건: 관리규약상 전유부 1/2·공유부 2/3(임차인 서명 가능).

[단지 팩트 — 그대로만 사용]
- 일광노르웨이숲오션포레: 부산 기장군 일광신도시, 11개동 1,294세대(23~29층), 전 평형 33평 이상(84㎡ 약 65%), 2027년 3월 입주.
- 일광신도시 최초 리조트형 하이엔드: 삼성물산 에버랜드 조경사업팀이 '조경'(약 1만 평) 설계·시공, 노르딕하우스 커뮤니티 약 1,300평, 오션뷰.
- 주의: 시공사는 유림이앤씨(삼성물산이 아님 — 삼성은 조경만). 부울양 광역철도는 일광역에 정차하지 않으므로 교통 호재로 쓰지 말 것(동해선 일광역·오시리아 관광단지로만).

[금지]
- 경쟁사 이름·비방 일절 금지. 대신 "어느 주관사를 뽑으시든 ①면허 ②예치금이 누구 돈·어느 통장인지 ③지역업체 비율 ④실적 계약서를 확인하십시오" 체크리스트 역제안 방식.
- 아크로/조명/커튼 등 자사 제품 '판매' 표현 금지(혜택·시공 지원으로만).

아래 [슬라이드 구성]대로 24장을 만들어라. 각 장: 헤드카피(1줄) + 보조카피(1~2줄) + 시각 요소 제안.
```

## §2. 기존 PPT 고치기 — 슬라이드별 수정 지시 (이게 제일 빠름)

| 슬라이드 | 수정 |
|---|---|
| 7 | "협의회 계좌에 예치" → **"입예협·주관사 공동통장에 예치, 집행권은 협의회 단독"** / 시점 = "협약식과 동시에" 유지 |
| 8 | "부산 최초 리조트형" → **"부산 일광신도시 최초 리조트형"** |
| 9·10 | 83만 구성에 **"+ 화재보험 무료"** 추가 |
| 11 | 끝줄에 **"하자점검 '우리홈' 협업(공용부 무료) · 경품 1위 바디프랜드 · 공용부 실링팬+간접조명 3개소 무료시공 · 세스코 공용부 소독"** 보강 / 베이스캠프 **1개월** |
| **12** | 전면 교체 → **"유리난간, 검토가 아니라 단가표를 들고 왔습니다"**: ①부산 첫 공동구매 완주 — 에코델타 푸르지오린 **120세대** ②이 단지 전용 단가 **개인 320만→10세대 공동구매 200만(−37.5%)** ③시공파트너 중원유리산업(특허 2건·삼성화재 배상책임보험·**같은 기장군 쌍용오시리아 시공**) ④행위허가~사용검사 원스톱 대행(동의: 전유부 1/2·공유부 2/3, 임차인 가능) |
| **14** | "지역업체 95%" → **"부산·경남 지역업체 100% — 못 지키면 자격철회 동의서에 지금 서명하겠습니다"** + **밴드 협력사 1,300곳 캡처** 이미지 + **🆕 클린벤더 라이브 시연 큐**("업체 평판을 지금 이 자리에서 검증해 보여드리겠습니다" — 노트북 전환 60~90초, 시연가이드 참조) |
| 16 | "협의회 계좌" → 공동통장·단독 집행 표현 통일 |
| **17** | "이행보증보험 2년 **10억**" → **"5억"** (증권 실물 지참) |
| 18 | "베이스캠프 45일" → **1개월** / "하자율 0%" → **"베이스캠프 운영 기간 미해결 하자 0건"** |
| 21 | "사송·에코델타 90%"와 "부산 70%+"는 모수가 다름 — 한 화면에 쓰려면 "특정 단지 기준 90% / 부산 전체 입주물량 기준 70%+"로 구분 |
| 24(Q&A) | 커닝페이퍼에 추가: **Q9 유림 유착**("계약 상대는 협의회, 1억 집행권도 협의회 단독") · **Q15 앱 개인정보**(동호수만·제3자 제공 금지·종료 시 파기) · **Q3 부스비 전가**("전가되면 최저가보장 차액 10배 — 구조적으로 불가") · **Q5 클린벤더 한계**("6단 검증의 2단계일 뿐 — 최종은 예치금·보증 5억이 거름") |

## §3. 슬라이드 구성(24장) — 생성/수정 공통 콘텐츠 골격
1. **표지** — 드론 항공샷 + "일광노르웨이숲오션포레 입주박람회 주관사 제안" (인사 직후 드론 30초)
2~6. **회사 소개(타일 A·실체)** — 면허 3종 직접시공 법인 → 인증(ISO·BB-) → 삼성전자 MOU → 조직 → 14지사·차 20분 사옥
7. **약속의 선언(타일 D)** — "협약식과 동시에, 현금 1억. 공동통장. 집행권은 협의회." (수미상관 오프닝)
8. **단지 이해** — 일광신도시 최초 리조트형·1,294세대·2027.3 / "오션뷰인데 유리난간 얘기는 잠시 뒤에"
9~11. **혜택(83만+α)** — 체크인만·전세대 동일·계약 0건 / 품목+화재보험 / "83만이 끝이 아니라 시작"(운영 약속 리스트) + **"왜 이 품목인가": 입주하면 어차피 할 것 × 2026 트렌드(스마트홈·호텔식 간접조명) × 리조트 단지 눈높이**
12. **유리난간(신무기)** — §2의 12번 내용
13. **모객·콘텐츠(타일 C)** — 드론·유튜브·카페·언론 (영상 상영)
14. **업체 검증(신무기)** — 6단 게이트 + 지역 100%·1,300곳 + **클린벤더 라이브 시연**
15~18. **안전망(타일 D)** — 4중 안전망 → 현금 1억(공동통장) → 이행보증 5억·도산 시 승계 → A/S 체계(48h·베이스캠프 1개월·미해결 0건)
19. **타임라인** — D-9개월부터 입주 후 24개월
20. **입주민 앱(타일 C)** — 폰 라이브 데모
21. **트랙레코드(타일 B)** — 22,065세대 + **기장 유림노르웨이숲(같은 시행사·같은 브랜드) 기주관 = 결정타**
22. **요약** — 4타일 한 장(실체→경험→시스템→책임) + "1억으로 시작했으니 1억으로 닫겠습니다"
23. **대표의 진심** — 책 3권
24. **Q&A** — §2의 커닝페이퍼

> 발표 60~90초 시연 2회(클린벤더 S14·앱 S20)는 [시연가이드](../vendor-screen/시연가이드.html) A4 그대로.
