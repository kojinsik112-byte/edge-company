# ㈜포이시스 (Foresys) — 기업 분석
> 분석 2026-06-11 · 출처: 잡코리아·사람인 기업정보 + foresys.co.kr
> 의뢰: 회장 "포이시스 광고대행업 알아봐"

## 0. 한 줄 정의
**서울 가산동의 IT·금융솔루션 + 온라인광고 회사.** 국내 최초 인터넷대출시스템을 만든 핀테크/SI 기반에 '온라인 광고대행'을 함께 하는 곳. **분양광고 특화 회사는 아님.**

## 2. 무슨 일을 하나 (사업 영역)
- **금융 IT 솔루션**: 국내 최초 **인터넷대출시스템** 구축. 금융 컨설팅·시스템·대출업무 대행.
- **온라인 광고대행**: 차별화 온라인광고 전략 + **Media Mix**. 자체 광고분석/최적화 솔루션 보유:
  - **DMS(드림온광고분석시스템)** — 광고캠페인 사전예측·효과분석·최적화
  - **FMS 2.0** — 광고 캠페인 관리·최적화 솔루션
- H/W·S/W 도소매, 운송장비 임대 등 부수 사업.
- → **'기술(데이터·솔루션) 기반 온라인 광고'**가 색깔. 오프라인 분양 크리에이티브 회사와는 결이 다름.

| 본사 | 강남 논현동 | 가산동 |
| 아파트 분양 색깔 | **강함**(현대·한화·포스코·호반 등) | 약함(분양 특화 아님, 온라인·금융 중심) |

→ **룩스 = 분양광고 전문(작지만 특화)** / **포이시스 = 규모 큰 IT·온라인광고(분양 특화 아님).** 둘은 같은 '광고대행'이라도 **성격이 많이 다름.**

## 4. ⚠️ 확인 필요 (중요)
- 회장님이 찾는 '포이시스'가 **이 회사(가산동 foresys, IT·금융+온라인광고)가 맞는지** — 만약 **분양광고 대행사 포이시스**를 따로 들으신 거면 동명이인 회사일 수 있음(별도 확인 필요).
- 비교 참고: 검색 중 **'포애드원'**(부동산 분양전문 광고대행, 매출 350억)도 나옴 — 분양광고 강자. 혹시 이쪽 의도면 알려주시면 분석.
