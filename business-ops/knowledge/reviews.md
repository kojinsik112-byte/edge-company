# 리뷰 인사이트 (review_miner)
> 자가성장 엔진 지식창고. 신규 리뷰가 확보되면 review_miner가 같은 형식(날짜별 append)으로 누적한다.
> 불만=개선기회 / 칭찬=셀링포인트 / 망설임=FAQ 로 분류해 기획·카피·CS에 연료 공급.

## 적재 형식 (예시)
```
## YYYY-MM-DD
- 출처: (네이버 리뷰 / 체험단 / 경쟁사 리뷰)
- 😞 불만(개선기회): ...
- 😀 칭찬(셀링포인트): ...
- 🤔 망설임(→FAQ): ...
- 액션: → planner/writer/cs 에 전달한 내용
```

> 아크로 슬림은 신상이라 자사 리뷰 공백 상태 → influencer 체험단으로 초기 리뷰 확보 후 여기에 누적 시작.
