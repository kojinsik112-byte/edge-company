# 엣지컴퍼니 통합제안서(152p) 수정 — 동탄 파라곤3차 입찰용

`fix_all.py` 하나로 3분할 원본(1-36 / 37-121 / 122-152)을 일괄 수정하고, 분할본 3개와 152p 합본 1권을 만든다.

```powershell
python fix_all.py <증빙폴더> 원본_1-36.pdf 원본_37-121.pdf 원본_122-152.pdf <출력폴더>
```
증빙폴더 파일명(고정): 사업자등록증.pdf · 법인등기부등본.pdf · 국세_납세증명서.pdf · 지방세_납세증명서.pdf ·
4대보험_가입자명부.pdf · ISO_인증서.pdf · NICE_기업신용평가.pdf

- 공식 증빙은 **원본 그대로** 액자에 맞춤(흰 바탕·비율 유지). AI로 증빙을 만들지 않는다.
- 이미지에 박힌 문구는 배경색 덧패치 + Pretendard 재기입(`retext`), 수정 목록은 출력폴더 `수정내역.txt`.
- **증빙·출력 PDF는 개인정보(4대보험 명부 등)가 있어 깃 제외**(.gitignore). 스크립트만 커밋.
