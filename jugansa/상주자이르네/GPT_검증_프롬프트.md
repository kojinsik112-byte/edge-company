# 상주 자이르네 제출본 — ChatGPT 재검증 프롬프트 (본부장 직접 실행용 · 10-26 2차)

목적: 운영위원이 우리 통합본을 ChatGPT에 올렸을 때 **그 화면에 뭐가 뜨는지** 확인한다. Claude가 같은 질문으로 재현한 결과(54점 · 오독 13 · 모호 22 · 약점 19)와 비교해, 2차 수정이 먹혔는지 본다.

## 0. 준비
1. **새 채팅**(가능하면 '임시 채팅') — 이전 대화 · 메모리가 섞이지 않게.
2. 파일 2개를 한 번에 올린다.
   - `[주식회사 엣지컴퍼니]_상주자이르네_주관사입찰서류.pdf` — 통합본 158쪽 · 약 75MB(10-26 2차 반영본)
   - 공고문 원본(본부장 보유 · 10.14 공고)
3. **모델 2번**(같은 프롬프트):
   - ① 기본(Auto) — 운영위원 대부분의 실제 조건
   - ② 고를 수 있는 가장 위 모델(Thinking · Pro · 추론, 생각 길게) — 가장 날카로운 지적용
4. 우리 내부 규칙은 알려주지 않는다. 'NICE 발급일 · 재발급' 지적이 나오면 무시(연 1회 정기 평가).

## 1. 역할 설정(첫 메시지 · 파일 올린 뒤)
```
너는 '상주 자이르네 입주예정자협의회' 운영위원이다. 773세대, 경북 상주시 함창읍, 2029년 4월 입주. 우리는 입주박람회 주관사를 뽑는 중이고, 공고 6항 서류심사 중점은 '시공 단계 품질 · 하자 예방 지원 계획'과 '분야별 전문인력(건축 · 토목 · 조경 · 전기 · 기계설비 · 소방) 역량'이다. 공고 7항에 따라 제안서는 협약서의 일부가 되고, 허위면 선정 후에도 해지된다.
올린 파일은 '주식회사 엣지컴퍼니'의 입찰서류 통합본(158쪽)과 우리 공고문이다. 지금부터 이 파일 내용만 근거로 답하고, 근거 쪽 번호(PDF 쪽)를 꼭 붙여라. 파일에 없는 건 '없음'이라고 말해라. 좋게 포장하지 말고 운영위원 입장에서 냉정하게 봐라.
```

## 2. 한 페이지 요약
```
이 업체 제안서를 한 페이지로 요약해 줘(핵심 약속 · 숫자 위주). 약속마다 붙은 조건(단서)도 빼지 말고 같이 적어 줘.
```

## 3. 공고 6항 채점
```
공고 6항 기준(시공 단계 지원 50 / 분야별 전문인력 50)으로 100점 만점 채점하고, 항목별 점수와 근거 쪽 번호를 적어 줘. 자격증 · 경력증 · 등록증 · 재직증명서가 실제로 첨부돼 있는지도 쪽 번호로 확인해 줘.
```

## 4. 빠져나갈 구멍 · 불일치 (가장 중요)
```
다음을 전부 찾아줘. 쪽 번호와 인용 문장을 붙이고 최대 20개.
1) 약속이 애매하거나 빠져나갈 구멍이 있는 문장('협의', '원칙', '노력', '가능' 등)
2) 서류끼리 안 맞는 숫자 · 날짜 · 책임 주체(같은 내용이 쪽마다 다르게 적힌 것)
3) 업체 규모(직원 수 · 거리)로 보아 지키기 어려운 약속
```

## 5. 안 지킬 가능성 · 협약 조건
```
이 업체가 협약 후 안 지킬 가능성이 큰 약속 Top 5와, 그걸 막으려고 협약서에 꼭 넣어야 할 조건을 적어 줘.
```

## 6. 2차 수정 확인(이번에 고친 곳 — 이 질문은 ①에서만)
```
아래 6가지를 이 파일에서 찾아서, 각각 '명확함 / 애매함 / 없음'으로 판정하고 근거 쪽과 문장을 인용해 줘.
1) 최저가 차액 10배 보상금은 누가, 언제까지 지급하는가
2) 공동구매 시공 품목의 무상 A/S 기간은 최소 몇 년이고, 쪽마다 같은가
3) 하자 접수 후 '48시간'은 방문 완료인가, 방문 일정 확정인가
4) 토목 · 기계설비 · 소방 전문인력은 확보됐는가, 진행 중인가
5) 실적 증명서(별지3호) 8건과 NICE 연혁 기록이 다른 이유가 적혀 있는가
6) 주말 · 공휴일 접수의 1차 회신 기준은 쪽마다 같은가
```

## 7. PT 질문 · 점수
```
2차 PT에서 이 업체에 물을 날카로운 질문 10개를 만들어 줘. 각 질문에 제안서 안에 답이 있으면 쪽 번호를, 없으면 '답 없음'이라고 표시해 줘.
마지막으로 서류심사 통과 가능성을 100점 만점으로 매기고 이유 3줄. 후하게 주지 마.
```

## 8. 결과 전달
- 모델 ① · ② 답을 **복사해서 채팅에 그대로 붙여넣기**(캡처보다 글자가 낫다). 시간이 없으면 4번(구멍 · 불일치) · 6번(2차 확인) · 7번(점수)만.
- Claude가 재현한 결과와 겹쳐 보고 **문장만 고쳐서 막을 수 있는 것**은 바로 고친다. 돈이 드는 새 약속 · 숫자는 본부장 결정.
- 참고: 스캔 쪽(등기부 p.4 ~ 5 · 지방세 p.7 · 인감 p.9 ~ 10 · 등록증 p.12 · 자격증 p.20 ~ 26 · 협약서 p.29 ~ 31 · NICE 연혁 p.34)은 ChatGPT가 '없음'으로 읽을 수 있다 — 그렇게 나오면 PT 첫 장에 '스캔본 · 원본 지참'을 적는다(서류는 그대로).
