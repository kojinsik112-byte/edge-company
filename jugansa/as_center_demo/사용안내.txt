엣지컴퍼니 A/S 도움 창구 - 시험판(내 PC에서만 돌아가는 판)

0. 다른 컴퓨터로 가져갈 때(압축 파일)
   - 'AS도움창구_시험판_….zip'을 USB · 메일 · 네이버 MYBOX 등으로 옮깁니다.
   - 압축 파일을 오른쪽 클릭 → '속성' → 아래쪽에 '차단 해제'가 있으면 체크 → 확인(인터넷으로 받은 파일만 해당).
   - 오른쪽 클릭 → '압축 풀기'(모두 압축 풀기)로 문서 폴더 등에 풉니다. 압축을 풀지 않고 안에서 바로 누르면 안 됩니다.
   - 'C:\Program Files' 같은 관리자 폴더에는 풀지 마세요(시연 데이터를 저장하지 못합니다).
   - 프로그램 설치는 필요 없습니다(PHP와 필요한 파일이 폴더 안에 다 들어 있음). 윈도우 10 · 11 64비트용입니다.
   - 처음 누를 때 'Windows의 PC 보호' 파란 창이 뜨면 '추가 정보' → '실행'을 누릅니다.
   - 방화벽 허용 창이 뜨면 '취소'를 눌러도 됩니다(이 PC 안에서만 쓰므로 바깥 연결이 필요 없음).

1. 여는 법
   - '시연_시작.bat'을 두 번 누릅니다.
     → 시연 데이터를 지금 시각 기준으로 새로 만들고, 브라우저에 시작 화면이 뜹니다.
   - 앞서 넣은 내용을 그대로 이어서 보려면 '이어서_열기.bat'을 누릅니다.
   - 끝나면 검은 창을 닫습니다(닫으면 시험판도 꺼집니다).
   - 시작 화면 주소: http://127.0.0.1:8091/demo.php

2. 시작 화면에 있는 것
   - 입주민 화면 · 관리 화면 · 업체 화면으로 바로 가는 링크
   - 관리 화면 아이디 · 비밀번호(시험판 전용)
   - 상태가 다른 시연용 요청 12건(주관사 개입 · 업체 확인 필요 · 방문 일정 확정 · 입주민 확인 대기 · 다시 열림 · 시공사 전달 · 마감)

3. 알아 둘 것
   - 실제 서버(가비아)에 올리기 전 시험판입니다. 이 PC 밖에서는 열리지 않습니다.
   - 문자는 실제로 보내지 않고 관리 화면 '문자 기록'에만 남습니다.
   - 단지 · 업체 · 입주민 이름과 전화번호(010-0000-…)는 모두 시연용입니다.
   - 관리 화면 '설정'의 '보안 연결(https) = 꺼짐'은 내 PC라서 그렇습니다. 실제 서버에서는 SSL을 켭니다.
   - 인터넷이 없으면 글꼴이 기본 글꼴로 바뀌고 '단지 · 업체'의 QR 그림이 안 나옵니다(나머지는 그대로 됩니다).
   - 다른 PC로 옮길 때는 이 폴더를 통째로 복사하면 됩니다(프로그램 설치 필요 없음).
