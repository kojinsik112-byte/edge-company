# 나리벡시티 제안서 — ChatGPT 검증 프롬프트 (본부장 직접 실행용)

목적: 입예협 운영진이 제안서를 ChatGPT에 올려 볼 때 **그 화면에 뭐가 뜨는지** 미리 본다. 글자만 읽히는 조건이라 디자인은 평가에서 빠진다.

## 0. 준비
1. **새 채팅**으로 연다(이전 대화 · 메모리가 섞이지 않게. 가능하면 '임시 채팅').
2. 파일 3개를 올린다(한 채팅에 한 번에):
   - `02_입주박람회_입찰_제안서.pdf` — 보관함 https://claude.ai/artifact/3ztXoq3zhm1LfC7nifASUb 에서 'PDF 저장'(109쪽 · 약 71MB · GPT는 용량 문제 없음)
   - `요약제안서_주식회사 엣지컴퍼니.pdf` — 같은 보관함 A
   - 공고문 원본 PDF(본부장 보유 · 10.19 공고)
3. **모델 2번 돌린다**(같은 프롬프트):
   - ① **기본(Auto) 모델** — 운영진 대부분이 실제로 쓰는 조건. 이 결과가 '실제 심사 화면'.
   - ② **플랜에서 고를 수 있는 가장 위 모델**(이름에 Thinking · Pro · 추론이 붙은 것, 생각 시간 길게) — 가장 날카로운 지적용.
4. 우리 내부 규칙(NICE 연 1회 · 비용 꼬리표 없음 등)은 **알려주지 않는다**. 운영진도 모르고 보니까. 결과에 'NICE 발급일' 지적이 나오면 무시(규칙 1).

## 1. 역할 설정(첫 메시지 · 파일 올린 뒤)
```
너는 '롯데캐슬 나리벡시티 입주예정자협의회' 운영진이다. 671세대, 의정부, 롯데건설, 2027년 11월 입주. 우리는 입주박람회 주관사를 뽑는 중이고, 올린 파일은 '주식회사 엣지컴퍼니'가 낸 제안서(109쪽), 요약제안서(12쪽), 우리 공고문이다. 지금부터 내 질문에 이 파일 내용만 근거로 답하고, 근거가 있는 쪽 번호를 꼭 붙여라. 파일에 없는 건 '없음'이라고 말해라. 좋게 포장하지 말고 운영진 입장에서 냉정하게 봐라.
```

## 2. 10줄 요약
```
이 제안서 핵심만 10줄로 요약해줘. 숫자가 있으면 숫자로.
```

## 3. 장점 · 단점
```
우리 입주예정자협의회 입장에서 이 업체의 장점 5개, 단점·리스크 5개를 뽑아줘. 각각 근거 쪽 번호와 인용 문장을 붙여줘.
```

## 4. 모호한 약속 · 모순 (가장 중요)
```
이 제안서에서 다음을 전부 찾아줘. 쪽 번호와 인용 문장을 붙이고, 최대 20개까지.
1) 모호한 약속 — '협의', '검토', '노력', '가능' 같은 말로 빠져나갈 수 있는 문장
2) 앞뒤가 안 맞는 숫자·기간·책임 주체 — 같은 내용이 쪽마다 다르게 적힌 것
3) 지킬 수 있을지 의심되는 조건 — 업체 규모(직원 수, 지사)로 보아 무리한 약속
4) 과장 표현 — 최고, 유일, 100%, 전국 최저 같은 말
```

## 5. PT 질문
```
우리가 2차 PT에서 이 업체를 몰아붙일 날카로운 질문 10개를 만들어줘. 각 질문마다 제안서 안에 이미 답이 있으면 그 쪽 번호를, 없으면 '답 없음'이라고 표시해줘.
```

## 6. 정회원 투표 인상 (요약제안서)
```
3차는 정회원 온라인 투표다. 일반 입주민은 요약제안서 12쪽만, 그것도 앞 2쪽 정도만 보고 찍는다. 요약제안서 앞 2쪽만 읽은 입주민이 받는 인상을 3줄로 말하고, 투표에서 불리해질 표현(어렵거나 차갑거나 업체 중심인 문장) 5개를 쪽 번호·인용과 함께 뽑아줘.
```

## 7. 경쟁사 공격 · 점수
```
이번엔 반대로, 네가 경쟁 주관사라고 치자. 이 제안서를 운영진 앞에서 깎아내리려면 어디를 공격하겠어? 7개를 근거 쪽 번호와 함께. 추측이면 '추측'이라고 써.
그 다음 운영진으로 돌아와서, 1차 서류심사 통과 가능성을 100점 만점으로 매기고 이유 3줄. 후하게 주지 마.
```

## 8. 결과 전달
- 모델 ① · ② 답을 **복사해서 채팅에 그대로 붙여넣기**(캡처보다 글자가 낫다). 7개 다 안 돼도 4번(모순)과 7번(점수)은 꼭.
- Claude가 돌린 시뮬레이션과 겹쳐 보고, **문장만 고쳐서 막을 수 있는 것**은 바로 고친다. 돈이 드는 새 약속은 본부장 결정.
