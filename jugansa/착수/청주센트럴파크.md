1. **서식1 하자보수 이행각서** — '참여 업체가 납품한 공사 및 물품' 하자를 주관사가 '즉시 … 상단(상당) 금액 변상' · 금액 한도 없음 · 보증기간은 '계약(또는 협약) 일반조건에 따라'로 서식에 정해지지 않음. 범위는 공동구매 품목 = 규칙 18과 같음(건설 하자 아님) → **서식 문구는 고치지 않고**, 제안서 A/S 쪽은 서식을 줄이는 조건(상한 · '업체 먼저' 순서)을 달지 않고 보증기간(시공 품목 최소 2년 · 제조사 보증)과 '건설 하자 = 시공사 책임'만 적는다. 10배 보상(1건 최대 50만원)은 별도 제도로만 표기. 서식1 서약 = 한도 없는 직접 변상이라는 점은 본부장이 알고 서명(내부).
2. **서식2** — 목록 이름 '단지 영업행위 금지' ↔ 서식 제목 '이의 제기 금지'. '미선정 시 이 단지 박람회 · 공동구매 개최 일절 금지'(기한 없음) · 일괄 도급 금지 · 이의 제기 금지. 묻지 않고 그대로 낸다(물으면 범위만 넓어짐). 제안서에 '위탁 · 대행 운영'으로 읽힐 문장 금지.
3. **유의 ② '불법 발전기금 제안 금지'** — 15만원 = 주관사가 직접 사서 세대에 드리는 선택 항목(현물). '발전기금 · 발전지원금 · 지원금' 단어 0건 · 같은 쪽에 '협의회 계좌 · 현금 지급 없음 · 세대에 품목으로 직접 전달' 한 줄.
4. **형식 · 순서 상이 = 제외** — 첨부 방식(위 판정) · 번호 = 공고 ① ~ ⑪.
5. **유선 연락 = 심사 제외** — 문의 · 회신 모두 메일. 카페 가입 · 쪽지 · 댓글 안 함.
6. **PT 일정 겹침** — 입예협 '지정' + 유의 ④(협의 비협조 = 제외) · 자격 ⑦(PT 직접 방문). 질의에 다른 단지 PT를 알리지 않고, 11.03 통보 뒤 대응(발표자 2인 체계는 내부 준비).
7. **유의 ③ 제안 내용 = 이행 책임 · ⑦ 협의회 일방 해지** — (안) · 상당 · 선택 항목 표기 유지 · 증자 · 지사 등기를 '완료'로 읽히게 쓰지 않음.
