# 엣지컴퍼니 A/S 도움 창구 — 가비아 설치 안내

PT 시연판(`C:\본부장\04주관사 제안서\AS접수창_시연판\as_demo.html`)과 같은 화면 · 흐름을 실제로 접수 · 저장 · 문자 발송까지 하게 만든 판입니다.
가비아 웹호스팅(PHP + MySQL)에 올려 씁니다. 프로그램을 따로 설치할 필요는 없습니다.

## 화면 4가지

| 주소 | 누가 | 하는 일 |

| `/admin.php` | 주관사 | 요청 관리(기한 · 개입 · 업체 지정/바꾸기 · 되돌리기 · 메모 · 업체별 성적 · 보고용 CSV) · 단지 · 업체(링크 · QR · 안내문 인쇄) · 문자 기록 · 설정 |

## 가비아에서 준비할 것(본부장님)

1. **웹호스팅 신청** — 리눅스 웹호스팅, PHP 7.4 이상(8.x 권장), MySQL(MariaDB) 포함 상품. 도메인을 정합니다(예: `as.edgecompany.co.kr`).
2. **보안 인증서(SSL)** — 호스팅 관리에서 무료/유료 SSL을 켭니다. 입주민 개인정보를 받으므로 **https는 꼭** 켭니다.
3. **DB 만들기** — 호스팅 관리 화면의 DB 이름 · 아이디 · 비밀번호를 적어 둡니다.
4. **가비아 문자 신청**(message.gabia.com) — 충전식. 단가는 신청 화면에서 확인.
   - 관리툴(sms.gabia.com) → 환경 설정 → **발신번호 등록**(회사 대표번호 · 통신서비스 이용증명원 등 서류 필요할 수 있음)
   - 기본 설정 → **API 발송 IP 설정**에 웹호스팅 서버 IP(호스팅 관리 화면에 나옴)
   - 관리자 → 서비스 정보 → **API 인증키** 확인
5. **개인정보 보호책임자** 이름 · 연락처를 정합니다(처리방침에 나옴).

## 올리기 · 설치(한 번)

1. 이 폴더(`jugansa/as_center`) 안의 파일을 FTP(가비아 웹 FTP 또는 FileZilla)로 웹 폴더(`www/` 또는 하위 폴더)에 올립니다. `README.md`, `.gitignore`는 안 올려도 됩니다. **`.htaccess` 두 개(맨 위 · lib 안)는 꼭** 올립니다.
2. `config.sample.php`를 복사해 `config.php`로 이름을 바꾸고 채웁니다.
   - `db` = 3번 DB 정보(type은 `mysql`)
   - `install_key` = 아무 글자(설치 화면에서 한 번 씀)
   - `privacy_officer` = 보호책임자
   - `sms` = 처음엔 `mode => 'off'`(기록만). 가비아 설정을 마치면 `sms_id` · `api_key` · `callback`(등록한 발신번호)을 넣고 `'gabia'`로 바꿉니다.
3. 브라우저로 `https://도메인/install.php` → 설치 열쇠 · 첫 관리자 계정 → **설치하기** → 끝나면 **`install.php`를 서버에서 지웁니다.**
4. `https://도메인/admin.php` 로그인 → **설정**에서 점검표가 모두 초록인지 확인(특히 'data 폴더 바깥 노출 = 막힘', 'https = 켜짐').
5. **단지 · 업체** → 단지 만들기 → 품목별 업체 등록(업체 이름 · 취급 품목 · 담당 휴대폰) → 안내문(QR) 인쇄.
6. '설정 → 내 휴대폰으로 시험 문자'로 문자가 실제로 오는지 확인 → 직원 휴대폰으로 시험 요청 한 건 넣어 전 과정(업체 링크 · 되돌리기 · 해결 확인)을 눌러 봅니다.

## 매일 하는 일(주관사 담당)

- 관리 페이지 '요청 관리'에서 **빨간 줄(주관사 개입)**과 **업체 확인 필요**만 챙기면 됩니다.
  - 업체 확인 필요 = 입주민이 업체를 모름 → 같은 품목 업체에 동 · 호로 확인 → '업체 지정 · 문자'
  - 주관사 개입 = 기한 안에 업체 표시가 없음 → 입주민에게 직접 전화 → '주관사가 직접 연락함' · 필요하면 '업체 바꾸기'
  - 아파트 자체 하자 = 시공사 하자 창구에 정리해 전달 → '시공사에 전달함' → 확인 뒤 '시공사 처리 확인함'
- 잘못 누른 단계는 '자세히 → 한 단계 되돌리기'(사유 필수, 이력에 남음).
- 주간 · 월간 보고는 '보고용 엑셀(CSV)'(이름 · 연락처 없이 접수 · 기한 · 처리 시각만).

## 기한 점검(크론)

따로 설정하지 않아도 접수창 · 관리 페이지가 열릴 때마다 10분 간격으로 기한 점검(재촉 · 주관사 개입 문자 · 보유 기간 파기)이 돕니다.
밤사이에도 정확히 돌리려면 바깥 크론 서비스에 `https://도메인/cron.php?key=config의 cron_key`를 10분마다 부르게 걸어 둡니다.

## 개인정보 · 보안

- 사진 · 문자 토큰 등은 `data/` 폴더에 두고 `.htaccess`로 바깥에서 못 열게 막습니다(설정 화면에서 확인).
- 사진은 휴대폰에서 1600px로 줄이고, 서버에서 다시 저장하면서 위치 정보 등을 지웁니다.
- 업체 링크는 업체가 바뀌면 새로 만들어지고(이전 링크 닫힘), 마감 30일 뒤 닫힙니다.
- 관리자 비밀번호는 암호화 저장, 5번 틀리면 10분 잠김, 2시간 안 쓰면 로그아웃. 관리자가 요청을 열어 본 기록 · 내보내기 기록이 `access_log`에 남습니다.
- 단지마다 '보유 기간 끝나는 날'을 넣으면 그날이 지나 그 단지 요청의 이름 · 연락처 · 내용 · 사진을 지우고 통계만 남깁니다.

## 내 PC에서 시험(개발용)

`config.php`의 `db`를 `['type' => 'sqlite', 'path' => __DIR__ . '/data/as.sqlite']`로 두고 PHP 내장 서버로 엽니다.

```
php -S 127.0.0.1:8090 -t .
```
