# EDGE Grand Draw — 입주민 댓글 이벤트 추첨기

엣지컴퍼니 주관사 전용 추첨 무대. `index.html` 하나로 동작합니다. 크롬으로 열면 되고 설치는 필요 없습니다.
(인터넷이 없으면 고급 글꼴 대신 기본 글꼴로 나오지만, 추첨 기능은 그대로 작동합니다.)

## 3단계 사용법
1. **참여자 불러오기**: 엑셀(.xlsx)이나 CSV를 끌어다 놓습니다. 또는 **네이버 카페 댓글 화면을 통째로 복사해 붙여넣기**만 해도 됩니다.
   - 닉네임에서 동호수를 자동으로 분리합니다: `110동 1201호 하늘맘B`, `1051404`, `105 2002 별빛A` → 동호수 + 닉네임
   - 주관사(엣지컴퍼니) 안내 댓글은 자동으로 제외합니다.
   - 같은 사람이 여러 번 쓴 댓글은 1번만 응모 처리합니다. `세대당 1회`, `댓글 수만큼 응모권` 중에서도 고를 수 있습니다.
2. **상품 설정**: 등수, 상품명, 인원을 입력합니다. 추첨은 낮은 등수부터 진행합니다(끝까지 자리를 지키게 하기 위해서).
3. **무대 열기**: 상품마다 추첨 방식을 바꿀 수 있습니다.

| 방식 | 언제 쓰나 | 긴장감 장치 |
|---|---|---|
| 골든볼 | 대표 추첨, 참여자가 많을 때 | 미끼 구슬이 출구까지 갔다가 떨어지는 페이크, 심장박동, 스포트라이트 |
| 마블 레이스 | 1등처럼 크게 띄울 때 | 전원이 구슬로 경주, 결승 직전 슬로모션 |
| 사다리 | 인원이 적은 상품 (당첨 + 꽝) | 덮인 카드가 떨리다가 뒤집힘 |
| 네임 룰렛 | 커피 쿠폰처럼 인원이 많은 상품 | 한 칸 앞에서 멈춘 척하다가 마지막 한 칸 이동. `한 번에` 버튼으로 일괄 추첨 |

당첨 공개는 **동 → 호수 → 닉네임 한 글자씩** 순서로 진행합니다. 진행 중에 `바로 공개`(Space)를 누르면 건너뜁니다.

## 결과와 공지
- **카페 공지문 복사**: 당첨자별 `동호수 닉네임`, 원래 댓글, 엣지컴퍼니 화답을 묶어 공지 글로 만듭니다. 엑셀에 `화답 댓글` 열이 있으면 자동으로 들어갑니다.
- **공정성 기록**: 읽은 댓글 수, 중복 정리, 추첨 대상, 난수 방식(Web Crypto), 시각을 남깁니다. 캡처해서 공지에 붙이면 됩니다.

## 카페 댓글 → 엑셀 (화답 댓글 작성용)
```bash
python tools/cafe_to_xlsx.py 카페댓글복사본.txt 참여자.xlsx
```
시트는 3개가 나옵니다. `참여자`(동호수·닉네임·댓글·화답)는 추첨기에 그대로 넣는 시트이고, `원본·작성일시`와 `검토 필요`(중복, 한 세대 여러 계정, 주관사 댓글)는 확인용입니다.

## 개인정보
- 참여자 데이터는 브라우저 메모리에만 있고 서버로 전송하지 않습니다. 저장되는 값은 상품, 제목, 옵션뿐입니다.
- 실명이나 연락처가 있는 명단은 `개인정보 가리기`로 김*늘 · 101동 12**호 형태로 표시합니다. 카페 공개 닉네임 데이터는 기본으로 그대로 보여줍니다.
- 실제 명단 파일은 `data/` 폴더에 두세요. 이 폴더는 git에서 제외되어 있습니다.

## 개발 메모
- 단일 파일: CSS, JS, 물리엔진(구슬 충돌, 회전문, 사다리)을 모두 직접 구현했습니다. 외부 스크립트는 구형 .xls를 열 때만 SheetJS를 불러옵니다.
- .xlsx는 브라우저 내장 압축 해제(DecompressionStream)로 직접 읽습니다. CSV는 UTF-8과 CP949를 자동으로 인식합니다.
