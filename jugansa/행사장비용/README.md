# 박람회 행사장 비용 계산기

- 게시본(비공개 아티팩트): https://claude.ai/artifact/4bpHsprcr7NJJc2UH29YqN — 손익계산기 운영비의 입력값.
- 36개 홀(코엑스 포함 — 제안서에서만 코엑스 제외) · 대관일수/박람회일수 · 계절(난방/냉방/봄·가을) + 냉난방 사용/안 함 · 냉난방 행사일 12시간(설치일 끔) · 전기 업체 사용분 3배 · BEXCO 제2전시장 요율 0.9 · 전기·냉난방 슬라이더 500~2,000만(박람회 3일 기준, 일수 비례) · 행사진행비 1,000만 · 부가세 별도.

## 파일
| 파일 | 내용 |
|---|---|
| `units.json` | 홀별 1월/8월 단가(E 임대·G 요율·H 관리·I 전기·K/M 냉난방), 면적(㎡), 문의처 |
| `model4.js` | 계산식(임대·관리·전기·냉난방) |
| `tpl4.html` | 화면(템플릿) — `/*MODEL*/` `/*DATA*/` 자리에 위 두 파일이 들어감 |
| `build.py` | → `박람회_행사장_비용.html` (아티팩트에 올리는 파일) |
| `verify_excel.py` | 회장 엑셀 '행사장 비용비교'와 대조(1,444항목 + 규모별 31행, 0 오류) — 엑셀은 깃 제외 |
| `robust.js` | 이상 입력·저장값 손상 13가지 점검(Playwright) |

## 고치는 법
1. 단가 수정 → `units.json` / 계산식 → `model4.js` / 화면 → `tpl4.html`
2. `python build.py` → `python verify_excel.py . <엑셀>` → 아티팩트를 같은 URL로 재게시

## 대기
- **BEXCO 사용 내역서(실제 계산서)** 받으면: 냉난방 단가, 전기 배수(현재 3배), 제2전시장 임대를 실제 값으로 맞춘다.
