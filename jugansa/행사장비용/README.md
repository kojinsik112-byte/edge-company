# 박람회 행사장 비용 계산기

- 게시본(비공개 아티팩트): https://claude.ai/artifact/4bpHsprcr7NJJc2UH29YqN — 손익계산기 운영비의 입력값.
- **v7 (2026-10-14) — 벡스코 전시장 사용료 정산서 2건으로 보정**(2025.12 제2전시장 4B · 2026.05 4E+4F). 정산서 원본은 담당자 연락처가 있어 깃 제외.
- 37개 홀(코엑스 포함 — 제안서에서만 코엑스 제외) · 대관일수/박람회일수 · 계절(난방/냉방/봄·가을) + 냉난방 사용/안 함 · 부가세 별도.
- 운영비 = 대관료 + **제사용료**(전기 · 냉난방 · 폐기물) + 행사진행비(기본 1,000만).
  - 제사용료 기본 '홀 단가 · 실측 보정': 전기 = 면적 × 0.24kWh/㎡·대관일 × 대관일수 × kWh 단가(배수 기본 1), 냉난방 = 면적 × 하루 가동시간 단가 × 박람회일(기본 9시간 · 설치일 끔), 폐기물 = 면적 × 195원. 단가 없는 홀은 중앙값 추정.
  - '직접 입력': 슬라이더 50~2,000만(박람회 3일 기준, 냉난방 포함 예산, 박람회일수 비례).
- 벡스코 제2전시장 4홀: 2026 단가 2,050원/㎡·일, 장소 등차율 1.00, 월별 1·2·7·8·12월 0.80 · 5월 1.10, 전기 232원(12월)·169원(5월), 냉난방 26원/㎡·시간(2025.12). 3층 5홀은 장소 0.9(본부장 기준, 정산서 없음).

## 파일
| 파일 | 내용 |
|---|---|
| `units.json` | 홀별 1월/8월 단가(E 임대·G 요율·H 관리·I 전기·J/K/M 냉난방), `spr`(봄·가을 실측 덮어쓰기), 면적(㎡), 문의처 |
| `model4.js` | 계산식(임대·관리·전기 'area'/'band'·냉난방·폐기물·중앙값 추정) |
| `tpl4.html` | 화면(템플릿) — `/*MODEL*/` `/*DATA*/` 자리에 위 두 파일이 들어감 |
| `build.py` | → `박람회_행사장_비용.html` (아티팩트에 올리는 파일) |
| `verify_bexco.js` | 벡스코 정산서 2건 대조 — 임대·냉난방 원 단위 일치, 전기 ±7%·폐기물 ±9% |
| `verify_excel.py` | 회장 엑셀 '행사장 비용비교'(엑셀 원래 가정 = 'band' 전기)와 대조(1,444항목 + 규모별 31행, 0 오류) — 엑셀은 깃 제외 |
| `robust.js` | 이상 입력·저장값 손상 13가지 점검(Playwright) |

## 고치는 법
1. 단가 수정 → `units.json` / 계산식 → `model4.js` / 화면 → `tpl4.html`
2. `python build.py` → `node verify_bexco.js` → `python verify_excel.py . <엑셀>` → 아티팩트를 같은 URL로 재게시
3. 새 정산서가 오면 `verify_bexco.js` CASES와 `tpl4.html` CAL에 당시 단가(u)와 실측(a)을 추가.
