# 엣지컴퍼니 AI 입찰본부 — 프롬프트 · 팀 사용 가이드

> 대상: 주관사업 총괄 본부장 윤현욱 · 작성 2026-10-20
> 지난 9 ~ 10월 단지 10곳(동탄 · 철산 · 탕정 · 지웰 · 분당 · 오산 · 고양 · 판교 · 북수원 · 상주)을 하면서 실제로 잘 먹힌 지시를 정리했습니다.

---

## 1. 핵심 원리 3가지

1. **한 번에 묶어서 지시** — "1) 2) 3)"으로 모아 주시면 한 번에 고치고 한 번에 다시 만듭니다. 조각조각 주시면 다시 만드는 횟수와 업로드가 늘어납니다.
2. **업로드 여부를 끝에 한 마디** — "만들어만 줘(업로드 X)" / "ZIP으로만 올려줘". 말씀 없으면 만들기만 합니다.
3. **확정값은 숫자로** — "지원금 12만원", "작성일 10.26", "입사일 09.28". 애매하면 제가 보수적으로 넣고 노란 칸으로 남깁니다.

## 2. 추천 프롬프트 (복사해서 쓰세요)

### ① 새 단지 착수
```
[단지명] 공고 올릴게(첨부). 분석해줘 — 참여 여부 결론, 사업성 점수, 제출서류 체크리스트,
참가자격·평가표 대응, 함정 조항, 질의 메일 초안. 마감 [날짜].
```
- 담당: `bid_notice_analyst`(공고) + `realestate_analyst`(단지) + `bid_economist`(손익)
- 결과: 분석 md 1개 + 본부장 확인 질문 최대 5개

### ② 제안서 · 제출서류 전체 만들기
```
[기존 단지] 빌더 복제해서 [새 단지] 전체 만들어줘(제안서 + 제출서류 PDF 1개).
지원금 [N]만원 · 작성일 [날짜] · 실적은 [방식]. 업로드는 하지마.
```
- 담당: `pt_builder`(07장 맞춤) + `bid_docs`(서류 · 병합)
- 팁: 공고 양식(docx · hwp) · 단지 이미지 · 확정 숫자를 **같은 메시지에** 주시면 질문이 줄어듭니다.

### ③ 서류 미비 점검
```
[단지] 공고 기준으로 서류 미비 확인해줘 — 발급 기한, 날인 종류, 증빙 없는 실적, 노란 칸.
```
- 결과: 🔴 탈락 위험 / 🟠 감점 / 🟡 다듬기 표

### ④ 법정 검토 (새로 만든 `/court`)
```
/court [단지] 제출본            ← 간단판(검사 → 변호 → 판결)
/court [단지] 제출본 정밀판      ← 검사 여러 명이 따로 공격 · 교차 검증
```
- 언제: 제출 1 ~ 2일 전 마지막 관문. 다른 단지 잔재 · 지킬 수 없는 약속 · 허위 소지를 찾습니다.
- `/court`는 이 저장소의 프로젝트 스킬(`.claude/skills/court/`)입니다 — 이 저장소를 연 세션이면 바로 쓸 수 있고, "법정 돌려줘"라고 말씀하셔도 됩니다.

### ⑤ 한 번에 고치기
```
[단지] 수정: 1) [쪽 번호] ~ 2) ~ 3) ~ . 다 반영하고 [업로드 X / ZIP으로 올려줘].
```
- 쪽 번호는 **슬라이드 우측 상단 번호** 기준으로 말씀하시면 됩니다.

### ⑥ 날인 · 스캔 반영
```
[단지] 사용인감계(또는 별지 1 ~ 5) 날인 스캔 올렸어. 최종본 만들어줘.
```
- 법인인감은 제가 만들지 않습니다 — 출력용 PDF → 실물 날인 → 스캔만.

### ⑦ 행사장 조사
```
[단지] 근처 박람회 행사장 후보 3곳 — 면적, 거리, 요금, 개관 일정까지.
```
- 담당: `bid_venue`

### ⑧ 제출 메일
```
[단지] 제출 메일 문구 + 디자인(HTML) 만들어줘. 가운데 GIF 넣을 거야.
```
- 담당: `bid_mail` · 메일 제목 · 파일명은 공고 형식 그대로 맞춥니다.

### ⑨ 규칙으로 고정하기
```
앞으로 항상 [규칙] 해줘. 메모에 적어줘.
```
- `jugansa/CLAUDE.md`에 적어 두면 다음 세션에서도 지킵니다(예: 메일용 PDF 만들지 않기, 아랫지역 지사 순서).

### ⑩ 진행 확인
```
[단지] 얼마나 남았어? / 지금 뭐 하고 있어?
```

## 3. AI 입찰본부 조직도

```
                 주관사업 총괄 본부장 (윤현욱) — 결정 · 날인 · 발송
                                 │
                     Claude 총괄 (지휘 · 빌드 · 검증)
                                 │
   ┌──────────────┬──────────────┼──────────────┬──────────────┐
 분석 팀          제작 팀         서류 팀         검토 팀         현장 · 발송 팀
 bid_notice_     pt_builder      bid_docs        /court(검사 ·   bid_venue
 analyst         (제안서 07장)    (별지 · 증빙 ·   변호 · 판사)     (행사장)
 realestate_     designer ·      병합 · 날인     auditor         bid_mail
 analyst         infographic     규칙)           legal           (메일 · 체크리스트)
 cafe_insight    (시각화)
 bid_economist
 (손익 · 지원금)
```

| 팀 | 에이전트 | 하는 일 | 새로 만듦 |
|---|---|---|---|
| 분석 | `bid_notice_analyst` | 공고 해부 → 제출서류 · 자격 · 평가 · 함정 체크리스트 | ✅ |
| 분석 | `realestate_analyst` | 단지 세대 · 타입 · 시공사 · 분양 현황 | 기존 |
| 분석 | `cafe_insight` | 입주민 카페 관심사 | 기존 |
| 분석 | `bid_economist` | 사업성 100점 · 순익 시나리오 · 지원금 상한 | ✅ |
| 제작 | `pt_builder` | 제안서 스토리 · 단지 맞춤 장 | 기존 |
| 서류 | `bid_docs` | 별지 원문 작성 · 발급일 · 가림 · 날인 규칙 · PDF 1개 병합 | ✅ |
| 검토 | `/court` 스킬 | 검사 → 변호 → 판결(탈락 · 허위 · 약속 위험) | ✅ |
| 검토 | `auditor` · `legal` | 사실 · 표시광고 · 법적 리스크 | 기존 |
| 현장 | `bid_venue` | 행사장 후보 · 면적 · 요금 | ✅ |
| 발송 | `bid_mail` | 메일 문구 · 디자인 · 발송 체크리스트 | ✅ |

### 한 단지가 흘러가는 순서
1. **공고 수령** → 분석 팀(①) → 본부장 결정(참여 · 지원금)
2. **빌드** → 제작 · 서류 팀(②) — 노란 칸 = 본부장 자료 대기
3. **미비 점검**(③) → **법정 검토**(④) → 한 번에 고치기(⑤)
4. **날인 · 스캔**(⑥) → 최종본
5. **메일 · 발송**(⑧) → 필요하면 업로드("ZIP으로 올려줘")

## 4. 본부장님이 미리 챙기면 빨라지는 것

| 자료 | 언제 | 왜 |
|---|---|---|
| 사업자등록증 · 등기 · 국세 · 지방세 · 인감증명서 | 매달 초 재발급 | 공고마다 '1개월 이내' 조건이 많음 |
| 4대보험 가입자 명부 | 입사 · 퇴사 반영 후 | 재직증명서 대상과 명부가 맞아야 함 |
| NICE 등급확인서(민간제출용) | 공고가 '1개월 이내'면 | 평가표 신용 점수 0점 방지 |
| 협약서 사본(가림본) | 단지별 1장씩 모아 두기 | '증빙 없는 실적 불인정' 공고 대비 |
| 전문가 자격증 · 협력 계약서 | 상주처럼 전문인력 요구 시 | 참가 자격 탈락 방지 |
| 법인인감 날인 | 출력용 받는 즉시 | 날인 스캔이 마지막 병목 |

## 5. 파일 위치 (참고)

- 단지별 폴더: `jugansa/<단지>/` — `build_xx.py`(제안서) · `docs_xx.py`(제출서류) · `data.py`(숫자는 여기 한 곳)
- 결과물: `<단지>/제출본/`(통합 PDF) · `<단지>/작업/제출현황.txt`(쪽 번호 · 조치) — 깃에는 올라가지 않음(개인정보)
- 팀 지침: `.claude/agents/bid_*.md` · 법정 검토: `.claude/skills/court/SKILL.md`
- 규칙 메모: `jugansa/CLAUDE.md`
