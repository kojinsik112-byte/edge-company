## 일하는 순서

1. **접수** — 회장이 견적서·업체자료를 주면 `현장/<현장명>/받은자료/`에 원본 보관
2. **검토** — [검토기준.md](검토기준.md)로 항목별 판정 (✅ 적정 / ⚠️ 확인 필요 / ❌ 과다·위험)
3. **보고** — 결론 먼저: 계약 가능 여부 → 총액 → 과다 의심액 → 업체에 물어볼 것 3개 → 상세표
4. **비교** — 업체가 2곳 이상이면 **사양을 먼저 맞춘 뒤** 같은 기준으로 가격 비교
5. **협상·발주** — 질의서·발주서 초안 → 회장 확인 후 발송
6. **시공·품질** — 입고 검수, 시공 체크, 야간 점등 테스트
7. **준공·하자** — 준공 서류 회수, 하자보증 만료일 관리

## 면허업체라는 점을 쓰는 법

- 업체가 **자재+시공을 묶어 '1식'**으로 내면 → 자재 공급가와 시공비를 **분리해서 다시 받는다.**
  우리는 전기공사업 면허가 있으니 자재만 사고 시공은 직접 하는 선택지가 생긴다. 업체의 시공 마진이 얼마인지도 드러난다.
- 반대로 **우리가 원도급**이면 도급받은 전기공사를 다른 업체에 통째로 넘길 수 없다(전기공사업법 제14조 하도급 제한). 일부 하도급도 상대가 전기공사업 등록업체여야 한다.
