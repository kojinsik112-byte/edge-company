# 경관조명 견적·업체자료 검토 기준

> 원칙: **사양을 먼저 맞추고, 그다음 가격을 본다.** 사양이 다르면 싼 게 싼 게 아니다.
> 시세 근거가 없으면 "근거 없음"이라고 쓴다. 추측으로 과다 판정하지 않는다.

## 0. 회장 보고 형식

1. 첫 줄 결론 — 계약해도 됨 / 조건부 / 다시 받아야 함
2. 총액 · 과다 의심액(근거 있는 것만) · 업체에 꼭 물어볼 것 3개
3. 항목별 표 — `항목 | 견적 | 판정 | 이유`
4. 판정 표시 — ✅ 적정 / ⚠️ 확인 필요 / ❌ 과다·위험

## 1. 견적서 구조 — 먼저 보는 것

| 확인 | 왜 |
|---|---|
| **'1식' 표기** | 등기구·전선·컨트롤러·장비비가 1식이면 **수량 × 단가 산출내역** 요구. 쪼갤 수 없는 것(연출 프로그래밍 일체 등)만 1식 허용 |
| **원가 구성이 나뉘었나** | 재료비 / 노무비 / 경비 / 일반관리비 / 이윤 / 부가세가 분리돼야 검증 가능 |
| **노무비** | 전기공사 표준품셈 × 전기공사 시중노임단가(내선전공 등)로 맞춰 본다 |
| **법정경비** | 산재·고용보험료, 산업안전보건관리비가 들어 있나. 빠지면 나중에 추가청구 |
| **일반관리비·이윤** | 공공공사 상한(국가계약법 시행규칙): 일반관리비 6% 이내, 이윤 15% 이내. 민간은 상한이 없지만 비교 잣대로 쓴다 |
| **자재+시공 묶음** | 분리 견적 요구 → 자재 직구매 + 자체 시공 선택지 확보 |

**나중에 추가청구 되기 쉬운 항목** — 견적에 들어 있는지 하나씩 확인:
고소작업차(스카이) 장비비 · 야간작업 할증 · 도로점용·교통통제 · 분전반·전원 인입 공사 · 사용전검사/점검 · 연출 프로그래밍·콘텐츠 제작 · 시운전·포커싱(조준) · 폐기물 처리 · 예비품

**계약 조건** — 납기 · 하자보증 기간과 보증금 · 지체상금 · 물가변동 · 설계변경 시 단가 기준 · 결제 조건(선급금 비율)

## 2. 자재(등기구) 사양 — 같은 물건인지부터

| 항목 | 확인할 것 | 옥외 경관조명 기준 |
|---|---|---|
| 인증 | KC(전기용품 안전인증) 필수. KS·고효율 인증은 가점(공공은 요구될 때 많음) | 인증번호로 조회해 **모델명이 견적 모델명과 같은지** |
| 방수방진(IP) | 설치 위치별 등급 | 외벽 노출 IP65 이상 / 지중매입·수변 IP67~68 |
| 충격(IK) | 사람 손 닿는 높이 | IK08 이상 권장 |
| 광원 | LED 칩·모듈 제조사, 광효율(lm/W), 연색성(CRI), 색온도, 수명(L70) | 카탈로그 숫자가 아니라 **시험성적서**로 확인 |
| 전원장치(SMPS) | 제조사·모델, 옥외형 여부, 서지 내성(kV)·SPD, 보증기간 | **경관조명 고장 1순위.** 모델 미기재면 ⚠️ |
| 재질·내식 | 알루미늄 다이캐스팅·도장 사양, 볼트 재질 | 울산 해안·공단 지역 → 염해·부식 대응(SUS316급 볼트, 내염 도장) |
| 배광 | 빔각(협각/광각), 투광 거리 | 조도 시뮬레이션(DIALux 등) 제출 여부 |
| RGB·미디어파사드 | 제어 방식(DMX512 / Art-Net / SPI), 컨트롤러 사양·채널 수, 스케줄·원격제어 | 고장 시 교체 단위(픽셀 1개냐 바 전체냐) |
| 보증 | 등기구·SMPS 각각 기간, 무상 AS 범위, 출동 시간 | 울산 현장 출동 가능 여부 |

## 3. 법·인허가

- **시공업체는 전기공사업 등록 필수** (전기공사업법 제3조). 하도급을 쓰면 하도급 업체 면허도 확인.
- **우리가 원도급이면 일괄 하도급 금지** (전기공사업법 제14조). 일부 하도급만, 상대도 등록업체여야.
- **공공 발주는 전기공사 분리발주 원칙** (전기공사업법 제11조).
- **시공관리책임자 지정** (전기공사업법 제17조) — 현장에 전기공사기술자 배치 여부.
- **빛공해방지법** — 조명환경관리구역(1~4종) 지정 지역이면 장식조명 휘도 기준을 맞추는지 설계 단계에서 계산서 요구.
- **경관법·지자체 경관조례** — 경관심의 대상이면 심의 통과안(색온도·연출·점등시간)대로 시공되는지.
- **사용전검사/점검·전기안전관리자** — 누가 하고, 비용이 견적 어디에 들어 있는지.

## 4. 업체 평가 (업체 자료 받았을 때)

| 확인 | 판정 기준 |
|---|---|
| 전기공사업 등록증 · 시공능력평가액 | 한국전기공사협회 공시로 대조 |
| 경관조명 준공 실적 | 실적증명서·계약서로 확인. **사진만 있는 실적은 '미확인'** |
| 제조사인가 유통사인가 | 제조사면 AS·납기 유리. 유통사면 원 제조사 확인 |
| 인증서·시험성적서 | 모델명 일치, 발행기관·발행일 확인 (다른 모델·오래된 성적서 주의) |
| AS 체계 | 울산 출동 가능 여부, 예비 재고 |

**위험 신호** — 하나라도 있으면 ⚠️ 이상
- '동등 이상'으로 모델을 안 밝힘
- 시험성적서 없이 카탈로그만 제출
- 광효율 등 수치가 업계 대비 비정상적으로 높음
- 보증 조건 미기재
- '1식' 도배
- 콘텐츠·프로그래밍을 '별도'로 빼 둠 (후청구)

## 5. 발주 (주문자)

발주서 필수 기재: **정확한 모델명 · 사양 · 수량 · 단가 · 납품 장소 · 납기 · 검수 조건 · 보증 기간 · 지체상금 · 결제 조건.**
초안은 본부장이 쓰고, 발송은 회장 확인 후.

## 6. 품질관리 — 입고 · 시공 · 준공

**입고 검수**
- 모델명·라벨·KC 마크가 발주서와 같은지, 수량
- 외관 — 도장 상태, 방수 개스킷
- 샘플 점등 — 색온도 로트 편차 확인. **같은 면에 다른 로트를 섞지 않는다**

**시공 체크**
- 방수 결선(정션박스·방수 커넥터), 케이블 고정·보호관
- 접지, 절연저항 측정, 긴 선로의 전압강하
- 고소작업 안전(추락 방지 조치)

**야간 점등 테스트**
- 실점등 확인, 투광기 포커싱(조준 각도), 연출 시나리오, 타이머·스케줄

**준공 서류**
- 준공도면·결선도, 컨트롤러 프로그램 백업, 운영 매뉴얼
- 예비품, 하자보증서, 시공 전·중·후 사진대장

**하자 관리**
- 보증 만료일을 달력에 등록하고, 만료 전에 일괄 점검 요청
