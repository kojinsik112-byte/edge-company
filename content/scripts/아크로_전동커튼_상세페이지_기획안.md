## 0. 이 상세페이지의 전략 한 줄
전동커튼은 "편해서 사는 게 아니라 **아침·저녁 삶의 질**"을 파는 상품.
→ **감성(아침 햇살 자동 오픈)으로 후킹 + 스펙(소음·하중·호환)으로 신뢰 + 생태계(아크로 통일)로 객단가.**
경쟁사는 '기능 나열'로 판다. 우리 +α = **하루 루틴 시나리오 + 아크로 스마트홈 세트**로 한 수 위.

## 1. 섹션 순서 (Shot-by-shot 상세페이지)

### ① 히어로 / 3초 후킹 (최상단)
- **비주얼**: 아침, 커튼이 스르륵 자동으로 열리며 햇살이 방에 퍼지는 컷 (영상/시네마그래프 권장).
- **헤드카피안**:
  - ★A "이제 커튼도 손대지 마세요" (편의)
  - B "아침 햇살이 알아서 들어옵니다" (감성)
  - C "말 한마디면 커튼이 열려요" (음성제어)
- **서브**: 앱·음성·리모컨·터치 — 4가지로 열고 닫는 아크로 전동커튼
- **신뢰 배지**: KC인증(번호 확정 필요) · 무타공 설치 · AS

### ② 공감 / 문제제기 (왜 필요한가)
스크롤 유도용 '내 얘기' 섹션. 각 1컷 + 짧은 자막:
- "아침마다 눈부심에 깨서 커튼 치러 일어나기 귀찮다"
- "무겁고 큰 거실 커튼, 매번 손으로 여닫기 번거롭다"
- "외출할 때 집이 비어 보이는 게 신경 쓰인다(방범)"
- "커튼 줄이 아이·반려동물에게 위험하다"
> 불만=기회. review_miner가 경쟁사 리뷰서 실제 불만 문구 뽑아 교체.

### ③ 솔루션 소개 — 아크로 전동커튼
- "그래서 만들었습니다" 전환. 제품 풀샷 + 핵심 한 줄.
- **한 문장 정의**: "기존 커튼 레일에 모터만, 앱·음성·리모컨으로 여닫는 전동커튼."

### ④ 핵심 셀링 3~4 (아이콘+큰 카피, 각 1스크린)
1. **4-way 제어** — 앱 / 음성(기가지니·구글·알렉사 중 지원 플랫폼 확정 필요) / 리모컨 / 손터치(살짝 당기면 자동)
2. **조용함** — 작동 소음 **(확정 필요)dB**, 새벽에도 옆사람 안 깨움
3. **무타공·간편설치** — 기존 레일 호환/교체, 약 **(확정 필요)분** 설치
4. **스케줄·자동화** — 기상/취침/외출 시간 예약, 일출연동(지원 여부 확정 필요)

### ⑤ 하루 루틴 시나리오 (+α · 감성 킬러섹션)
경쟁사엔 없는 우리 차별화. 타임라인 4컷:
- **07:00 기상** — 예약시간에 스르륵 오픈, 자연광 기상
- **12:00 외출** — "커튼 닫아줘" 음성 한마디 / 방범 모드 랜덤 개폐
- **19:00 귀가** — 리모컨으로 무드 조절(반쯤 열기)
- **23:00 취침** — 자동 클로즈 + (아크로 조명 디밍 연동 시) 조명도 같이 오프
> 이 섹션이 "왜 아크로냐"의 감정적 답. ecosystem 연동 훅 자연 삽입.

### ⑥ 스펙 인포그래픽 (infographic팀 — 아크로 승부처)
한눈에 들어오는 SVG/HTML 스펙표. **(전부 확정 필요 — 실측/사양 확보 후)**
| 항목 | 값 |
|---|---|
| 작동 소음 | (확정)dB |
| 최대 커튼 하중 | (확정)kg |
| 작동 속도 | (확정)cm/s |
| 지원 레일 길이 | (확정) ~ (확정)m |
| 개폐 방식 | 단개(한쪽) / 양개(가운데 분리) |
| 연동 플랫폼 | (확정: 기가지니/구글/알렉사/SmartThings 등) |
| 전원 | (확정: 상시전원/USB충전/배터리) |
| 소비전력 | (확정)W |
| 인증 | KC (번호 확정) |
> ⚠️ 수치는 확정 전 노출 금지. 표시광고법·전파인증(무선) 표기 legal 검토 필수.

### ⑦ 설치 안내 (진입장벽 해소)
- "우리 집도 되나요?" — 호환 레일 체크 가이드(레일 종류 그림).
- 무타공/기존레일 교체 스텝 3~4컷 + 설치영상.
- 어려우면 **엣지리브커튼 출장시공** 연결(생태계 시너지).

### ⑧ 아크로 생태계 락인 (객단가 섹션)
- "커튼만? 집 전체를 아크로로." — 실링팬·스위치·디밍조명·우물천장 간접조명과 **앱 하나·리모컨 하나 통일**.
- 세트/번들 유도(가격은 pricing팀). "실링팬 쓰는 집이면 커튼도 아크로로."

### ⑨ 신뢰 (구매 직전 불안 제거)
- KC인증(무선=전파인증 별도 확정) · 모터 내구 테스트(횟수 확정 필요) · AS 정책 · 리뷰(초기 공백은 influencer 체험단으로).

### ⑩ 구성·옵션·가격
- 옵션: 레일 길이/개폐방식(단개·양개)/색상 · 리모컨 추가 · 설치 포함/미포함.
- 가격: **(확정 필요)** — pricing팀 미끼·번들 시뮬 후. 무료배송·오늘출발 여부 표기.

### ⑪ FAQ (cs팀 — 망설임 제거)
예) 우리 집 레일에 되나요 / 정전되면 손으로 여닫아지나요 / 소음 심한가요 / 무거운 암막커튼도 되나요 / 설치 직접 가능한가요 / 음성 뭐 되나요.

### ⑫ 하단 CTA
- "지금 우리 집 창에 맞춰보기" + 옵션 선택 유도 + 생태계 배너.
