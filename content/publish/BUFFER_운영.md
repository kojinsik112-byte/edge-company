# Buffer 발행 운영 (buffer_ops) — 인스타·유튜브
> 팀: buffer_ops·publisher | 2026-06-09 | 회장 확인: 인스타가 Buffer에 연결됨 ✅

## 현실 (솔직)
- **발행 채널 준비 끝**: 인스타(+유튜브)가 Buffer에 연결돼 있음.
- **Buffer 자동 API는 제한적**(신규 토큰 발급 사실상 막힘) + 본부장 브라우저 도구는 buffer/facebook 도메인 차단(보안). → 우리가 Buffer 안을 자동 조작하진 못함.
- **그래서 운영 방식**: buffer_ops가 **Buffer에 바로 붙여넣을 완성 패키지**를 만든다 → 회장(또는 담당)이 Buffer 큐에 30초 투입 → Buffer가 인스타·유튜브로 자동 발행/예약.
- **진짜 남은 병목 = 영상(촬영).** 대본·샷리스트는 완성(`content/scripts`, `content/shootlist`). 회장 촬영본만 있으면 즉시 발행 가능.

## 패키지 → Buffer 투입 순서
1. buffer_ops가 영상 1편당 폴더 완성: 영상(9:16) + 커버 + **캡션(복붙)** + 해시태그 + 추천 발행시각.
2. Buffer 열기 → 채널(인스타/유튜브) 선택 → 영상 업로드 → caption.txt 붙여넣기 → 시간 예약(아래 표) → Queue.
3. 발행 후 URL을 `content/publish/발행로그.md`에 기록(analytics 추적).

## 추천 발행 시간 (KST)
| 채널 | 추천 시간 | 비고 |
|---|---|---|
| 인스타 릴스 | 평일 19:00~21:00, 토 11:00 | 리빙/인테리어 타깃 저녁 |
| 유튜브 숏츠 | 평일 18:00~20:00 | 검색의도 강함 → 제목 키워드 |
| (네이버) | 12:00·20:00 | 블로그/모먼트 |
> 정확 시간은 발행 후 analytics 데이터로 보정.
