## 0. 결론부터 (솔직)
- **지금 당장 가능:** 영상 1편당 "원클릭 수동 업로드 패키지"(영상+커버+캡션+해시태그+발행시각)를 폴더로 받아 → 회장이 각 앱에서 30초 컷 업로드. **계정만 있으면 오늘부터 가능.**
- **완전 자동(예약 자동발행)은 플랫폼별 연동 필요** — 아래 4번. 미연동이면 자동화는 막혀도 콘텐츠는 막히지 않게 패키지로 굴린다.

## 1. 플랫폼 규격 (이 규격으로 인코딩해서 패키지에 넣음)
| 플랫폼 | 비율 | 길이 | 권장 해상도 | 커버/썸네일 | 비고 |
|--------|------|------|-------------|-------------|------|
| 인스타 릴스 | 9:16 | ≤90초 | 1080×1920 | 1080×1920 커버 | 해시태그 3~5(롱테일) |
| 틱톡 | 9:16 | 15~60초 권장 | 1080×1920 | 자동/첫프레임 | 사운드=발행당일 픽 |
| 유튜브 숏츠 | 9:16 | ≤60초 | 1080×1920 | 첫프레임 강함 | 제목에 검색키워드 |
| 네이버 모먼트 | 9:16/1:1 | 짧게 | 1080×1920 | — | 스토어 연결 |
> ffmpeg로 마스터 1편 → 플랫폼별 자동 트랜스코드(아래 스니펫).

## 2. 업로드 패키지 구조 (영상 1편 = 폴더 1개)
```
content/publish/<영상명>/
├─ master.mp4              # 9:16 마스터(autoedit/촬영본)
├─ ig_reels.mp4           # 규격 변환본
├─ tiktok.mp4
├─ yt_shorts.mp4
├─ cover.jpg              # 1080×1920 커버
├─ caption.txt           # 플랫폼별 캡션(복붙) ← caption_writer
└─ publish.md            # 발행시각·체크리스트
```
회장은 **폴더만 열면** 끝. 앱에서 영상 고르고 caption.txt 복붙.

## 3. ffmpeg 규격 변환 스니펫 (social_publisher 운용)
```bash
# 마스터 → 유튜브 숏츠(≤60s), 릴스(≤90s) 동일 9:16이면 길이/비트레이트만 정리
ffmpeg -i master.mp4 -t 60 -vf "scale=1080:1920:force_original_aspect_ratio=decrease,pad=1080:1920:(ow-iw)/2:(oh-ih)/2" -c:v libx264 -b:v 8M -c:a aac yt_shorts.mp4
ffmpeg -i master.mp4 -vf "scale=1080:1920:force_original_aspect_ratio=decrease,pad=1080:1920:(ow-iw)/2:(oh-ih)/2" -c:v libx264 -b:v 10M ig_reels.mp4
```
> 세로 영상 원본이면 pad 대신 crop. video팀(autoedit)이 자막·BGM 입힌 뒤 여기로.

## 4. 자동 발행 — 무엇이 있으면 풀리나 (회장 제공/결정 필요)
| 플랫폼 | 자동발행 경로 | 필요한 것 | 현재 |
|--------|--------------|-----------|------|
| 인스타/페북 | Instagram Graph API (Reels 예약·발행) | ①인스타 **프로 계정** ②페북 페이지 연결 ③Meta 앱+토큰 | ❌ 미연동 |
| 유튜브 숏츠 | YouTube Data API v3 (upload) | Google OAuth 클라이언트+채널 권한 | ❌ 미연동 |
| 틱톡 | Content Posting API | 개발자 앱 **승인 심사** 필요(까다로움) | ❌ (수동 권장) |
| 네이버 | 공개 업로드 API 없음 | playwright CDP 자동화(naver-data-infra 방식) or 수동 | ❌ (수동/반자동) |
> **보안 원칙:** 토큰/비번은 `.env` 또는 회장이 직접 입력. 비밀번호 직접 입력 금지(naver-data-infra와 동일).
> 권장 순서: **인스타 그래프 API → 유튜브 API** 먼저 뚫으면 가장 효과 큼. 틱톡·네이버는 당분간 수동.
