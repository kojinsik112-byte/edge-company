## 0) 2026 알고리즘 공통 규칙 (전 플랫폼 적용 — 실제 확인)

이게 해시태그/자막보다 먼저다. 안 지키면 태그 아무리 좋아도 안 뜬다.

1. **첫 2초가 전부.** 숏폼은 첫 2초에 시선을 못 잡으면 알고리즘이 "저품질"로 분류. (출처: calywire, seosherpa)
2. **미스리딩 훅 = 페널티.** 첫 2초에 약속한 걸 영상 안에서 반드시 보여줘야 함. 10초 내 이탈 시 강등. (출처: calywire)
3. **핵심 키워드를 "입으로 말하고" + "자막으로 박고" + "캡션에 쓴다".** 틱톡·인스타·유튜브 모두 음성·화면자막·캡션을 스캔해 검색 매칭. (출처: seosherpa, snshelper)
4. **해시태그는 적게.** 인스타는 2026년 **3~5개 권장**(과거 30개 도배 끝). 롱테일 태그가 광범위 태그보다 유리. (출처: snshelper, shopify)
5. **롱테일 검색 최적화.** "#요리"가 아니라 "#집에서만드는간단한요리"식. 우리는 "#실링팬"보다 "#저천장실링팬"이 핵심. (출처: snshelper)
6. **틱톡·유튜브는 검색엔진화(제로클릭).** 사용자가 검색 안 해도 시청패턴 기반 홈에 자동 노출 → 일관된 주제·키워드 반복 발행이 권위 신호. (출처: seosherpa, fikad)

## 1) 인스타그램 (릴스 중심)

### 시장 맥락 (실제 확인)
- 인스타에 **#신혼인테리어(1M+ 릴스 규모), #자취방꾸미기, #원룸인테리어, #집스타그램** 생태계가 두텁다. @todayhouse(오늘의집), @haedal_home, @hyel_room, @butt.zip 등 집꾸미기 인플루언서 활발. (출처: instagram.com 검색결과)
- 해시태그는 캡션 또는 첫 댓글에 배치, **3~5개** 권장. (출처: shopify)

### 해시태그 묶음 — 즉시 복붙용 (대형/중형/소형 믹스)
> 규칙: 한 게시물에 **5개 내외**로 추려서. 대형 1~2 + 중형 1~2 + 소형(브랜드/롱테일) 1~2 조합. 전부 붙이지 말 것.

**A. 저천장 솔루션 앵글 (우리 1순위 무기)**
```
#저천장실링팬 #낮은천장인테리어 #슬림실링팬 #저천장솔루션 #아크로실링팬
```
**B. 집꾸미기/거실 앵글 (도달 확대)**
```

```
**C. 스마트/가전 앵글 (BLDC·블루투스)**

```
영문 보조(해외/탐색 노출): `#ceilingfan #lowceilingfan #homedecor #interiordesign`

### 자막에 박을 키워드 (화면 텍스트)
- "천장 2.3m 안 되는 집, 이거면 됩니다" / "14.5cm 숏바디"
- "선풍기 치웠더니 거실이 넓어짐"
- "블루투스로 누워서 끄는 실링팬"
- "전기료 걱정? BLDC라 한 달 OO원" ← 수치는 finance/brand_intel 실측치로 채울 것(과대광고 금지)

### 인기 포맷 (추정 — 인테리어 릴스 통념 기반)

### 해시태그 묶음 — 즉시 복붙용

### 검색 키워드 / 제목 패턴 — 즉시 복붙용
> 패턴: [후킹 숫자/반전] + [핵심키워드 앞쪽] + [결과]

- **숫자 자막 큼직하게**: "14.5cm" 단독 풀스크린.

### 시장 맥락 (실제 확인)
- 실링팬은 네이버에서 **"설치비용·단점·브랜드 추천·전기세·천장형 선풍기"** 축으로 정보탐색 수요가 큼(다수 비교/후기 블로그 존재). (출처: ajd.co.kr, kqwer, smbdi)
- **저천장 페인포인트가 공식 인정됨**: 실링팬은 천장 2.3m 이상 권장, 낮으면 '우물천장' 또는 **'슬림형 제품'으로 해결** — 우리 제품의 정확한 검색 수요 진입점. (출처: keyzard/우먼센스 인용)
- 2026 거실 트렌드 키워드: **워밍 뉴트럴·곡선·존 디바이드·플랜테리어**(오늘의집), 전반 '어시톤·소프트 미니멀리즘·생활감'. (출처: ohou.se, vogue, ampm)

### 타깃 키워드(연관/자동완성 공략 — 콘텐츠 제목·태그에 심기)
> ※ 검색량 수치는 미실측 → **seo팀이 naver_search.py / 키워드마스터로 실측 후 우선순위 확정**(추정).
```

[솔루션형] 저천장 실링팬 / 낮은 천장 실링팬 / 슬림 실링팬 / 우물천장 실링팬 / 저천장 거실 인테리어
[구매형] 실링팬 추천 / 블루투스 실링팬 / BLDC 실링팬 / 조용한 실링팬 / 실링팬 4색상

### 네이버 콘텐츠 운영 룰
- **블로그/포스트**: "저천장인데 실링팬 되나요?" 식 질문형 제목으로 정보형 검색 흡수 → 본문에서 14.5cm 슬림으로 해결 → 자연스럽게 제품 연결.
- 네이버는 **연관검색어/자동완성을 본문 키워드 빈도·체류시간으로 학습** → 정보형 페인포인트 콘텐츠를 꾸준히 쌓아 "실링팬+저천장" 연관 클러스터를 우리가 선점.
- 모먼트/쇼핑라이브: 설치 비포애프터 + 6단 풍속 + 블루투스 시연.

## 6) 지금 가장 밀어야 할 트렌드 포맷 TOP 3 (이번 주 집행 권고)

1. **"저천장 반전" 비포애프터 릴스/숏츠** — 우리만의 독점 시장(14.5cm). 첫 프레임 "손이 천장에 닿는 집" → 팬 회전. 핵심태그 `#저천장실링팬`. 인스타+틱톡+숏츠 3채널 동시.
2. **무소음 설치 ASMR 언박싱** — 언박싱/ASMR 대형 수요를 BLDC 저소음 증명에 연결. "소리로 증명"이 과대광고 없이 스펙을 보여주는 정공법.
3. **네이버 질문형 정보 콘텐츠 클러스터** — "저천장인데 실링팬 되나요?" 류로 정보형 검색을 선점 → 연관검색어 락인. 숏폼이 도달이라면 네이버는 구매 직전 검증 채널.
