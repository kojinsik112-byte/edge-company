## 1. 콘텐츠 기둥 (Content Pillars) — 5축
각 기둥은 구매여정의 특정 단계를 때린다. (persona·cro 연계)

| # | 기둥 | 핵심 메시지 | 구매단계 | 주력 플랫폼 |
|---|------|------------|----------|-------------|
| P1 | **저천장 솔루션** | "천장 낮아서 실링팬 포기했죠? 14.5cm" | 인지(문제 자각) | 릴스·숏츠(검색) |
| P2 | **설치 비포애프터** | "에어컨 옆 휑한 천장 → 5분 후" | 고민(상상 자극) | 릴스·틱톡 |
| P3 | **생태계 락인** | "팬 하나 달면 조명·스위치·커튼까지 앱 하나로" | 결정(객단가↑) | 릴스·유튜브 |
| P4 | **소음·전기료 실측** | "수면풍 ○○dB, 한 달 전기료 ○○원" *(실측 확정)* | 고민(불안 해소) | 숏츠(정보)·블로그 |
| P5 | **공간 무드** | 거실·침실·카페에 놓인 화보컷 슬로모 | 인지·브랜딩 | 인스타 피드·틱톡 |

> 비중(런칭 2주): P1·P2를 앞에 강하게(인지 확보), P3로 객단가, P4로 신뢰, P5로 브랜드 결.

## 2. 원소스 멀티유즈 (OSMU) 원칙
하나를 찍어 4채널로 재가공한다. (social_publisher가 규격 변환)
- **인스타 릴스** = 세련·감성 톤, 커버 텍스트 강조, 해시태그 10~20
- **틱톡** = 빠른 컷·구어체·트렌드 사운드, 해시태그 3~6
- **유튜브 숏츠** = 정보형 제목(검색 키워드 포함) + #Shorts
- **네이버 모먼트/블로그** = 정보+키워드, 스토어 연결
> 자막은 항상 **세이프존**(상하 15%) 비우고 촬영(shoot_director 지시) → 플랫폼 UI에 안 가림.

## 4. 촬영 묶음(Batch) 지시 — shoot_director에게
회장이 **한 번 세팅으로 최대한 많이** 찍게 묶는다.
- **Batch A (설치 현장 1곳)**: #1, #2, #6, #8 — 천장/설치/14.5cm 클로즈업·비포애프터 한 자리에서.
- **Batch B (스타일링 공간)**: #3, #5 — 4색상 무드컷 + 앱 제어 시연.
- **Batch C (정밀·소리)**: #4, #7 — 수면풍 소음 녹음, 계량기/스펙 클로즈업. *(실측 데이터 필요 → 회장 의존)*
