사용 방법

  1. 아래 각 칸을 클릭하거나 사진 파일을 드래그&드롭해서 올리세요.
  2. 저장은 자동입니다. 이 페이지 또는 사이트를 새로고침하면 바로 반영됩니다.
  3. 이미지는 이 브라우저에만 저장됩니다. 다른 PC나 폰에서도 같은 사진을 보려면 백업 내려받기로 JSON 파일을 받아두고, 다른 기기에서 백업 불러오기로 적용하세요.
  4. 사진 한 장당 2MB 이하 권장. 너무 크면 사이트가 느려집니다.
중요 · 이 관리자 페이지는 브라우저 저장소(localStorage)를 사용합니다. 인터넷 사용기록·캐시를 지우면 이미지가 함께 지워집니다. 백업 내려받기를 주기적으로 해두세요.
